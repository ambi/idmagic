# seed のリソース生成と差分判定を組み立て地点から移す

規範仕様の差分はない。
リソースの生成、比較と適用順を Seeding に移し、bootstrap をシークレットの提供元、ハッシュ器と所有者の保存契約の結線へ限定した。
Seeding は構築地点の全依存を受け取らず、必要な公開の保存契約だけを受け取る。
ファーストパーティークライアントの生成と比較は、時刻を引数に取る domain の計算とし、既存のパッケージ内テスト用の名前は委譲だけを残した。

計画、ドリフトの判定、保存の順序、再適用と永続状態を維持し、テストは変更していない。
設計の現在状態と生成したモジュール間の依存図を更新し、組み立て地点に判断が残るリスクを除いた。
Repository の直接保存の是正、プロセス間の排他、デモの詳細なドリフト検出は対象外とし、既存の wi-24943 と Seeding のリスクに残した。
