# 認可リクエストを、同意の要否に応じて ConsentPending と Consented の段に進める

認証完了を同意判定より前に保存し、同意が必要な認可要求を `ConsentPending`、許可後を `Consented → CodeIssued`、拒否後を `Rejected` に進める。
Cookie による継続を各段階へ対応させ、同意待ち以外の操作、未完了の認証、主体不一致では付与と発行を拒否する。
同意済みの主体を各認証入口で書き換えず、本人の再開だけが再同意なしに発行へ進める。
`spec-diff` 上の規範仕様の変更はなく、既存同意と第一者クライアントの省略経路を保つ。
検証範囲は変更パッケージと逆依存の Go テスト、拒否後の保存とイベント、認可のブラウザー E2E とし、同意画面の表示と文言は対象外とした。
