# リソースアクセスの評価に性能目標と流量制限を設ける

REQ-OAUTH2-062 と `EvaluateResourceAccess` に、認証したクライアントとテナントごとの固定窓の予算と 429 の応答を追加した。
デフォルトは毎秒 100 回とし、API プロセスの環境変数で上限と窓を調整できる。
カウンター障害でも評価を止め、超過で評価イベント、DPoP の証明の消費、承認の使用権、参照 PEP の業務作用を起こさない。

メモリと PostgreSQL の正式な構成で設定と HTTP の上限を検証し、直接関係と深さ 4、DPoP、失効を含む局所測定と再現タスクを追加した。
応答時間と局所処理量の目標、測定条件と結果、容量の仮定を品質要件と性能設計に記録した。
本番規模のデータ、ネットワーク、混合負荷と持続負荷は未検証であり、局所測定を本番の容量保証には使わない。
Agent やツールごとの上限と評価結果のキャッシュは対象外とした。
