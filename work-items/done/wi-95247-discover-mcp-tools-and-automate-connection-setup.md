# MCP サーバーと Gateway の登録をまとめ、接続準備を自動化する

REQ-OAUTH2-086〜088 と REQ-MCPGATEWAY-011 を追加し、REQ-OAUTH2-064 にスコープを省いた登録の扱いを加えた。
カタログを参照する Gateway は、起動後に上流の `tools/list` を集めて `POST /resource-access/tools` へ報告する。IdMagic は報告を登録とは別の `mcp_tool_reports` に置き、公開、評価、発行、割当は報告を読まない。IdMagic から MCP サーバーへの外向きの取得は作らなかった。
管理者は報告されたツールを編集画面で選んで公開し、ツール名と表示名を入力しない。完全な報告にない公開中のツールは示すだけで削除しない。
接続先の登録画面は評価用のクライアントの新規作成、名前での選択、なしを選べ、作成済みのクライアントを保って登録だけを再試行できる。結果に一度だけのシークレットと Gateway の設定の例を示す。
Gateway が執行する構成ではスコープが IdMagic の中だけの上限なので、利用者の判断により、省いた登録に `mcp` を補い、スコープの入力を詳細設定へ移した。
メタデータの取得、変更通知、Gateway のない直接取得、接続確認は wi-58793、Gateway の運用場所は wi-66764、Agent 側の一括作成は wi-85817 へ分けた。
