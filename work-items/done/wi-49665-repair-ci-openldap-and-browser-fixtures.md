# CI の OpenLDAP とブラウザーテストの前提を修復する

OpenLDAP の初期設定用の平文サーバーを準備完了と判定していたため、準備確認と管理操作を、テスト用 CA と証明書名を検証する LDAPS に揃えた。
別の CA を与えた管理接続を拒否する回帰テストを加えた。
接続先の平文への切り替えは採用した変異演算子で表現できないため、この境界で固定した。
同意画面を観測する認可 E2E は `prompt=consent` を明示し、共有スタックに保存済みの同意やファイルの実行順序への依存をなくした。
Entra の E2E は、即時の Hybrid Join を提供せず、Entra Connect の同期後に登録される現行の案内を表明する。
製品の LDAP の証明書検証、認可と同意、Entra の提供範囲は変更せず、規範仕様の差分はない。
