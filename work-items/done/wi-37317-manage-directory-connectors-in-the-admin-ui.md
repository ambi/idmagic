# 管理画面で Directory Connector を登録し、同期の状態を確かめられるようにする

管理画面に Directory Connector の一覧、作成、詳細を追加した。
`spec-diff` の差分は REQ-SOURCING-023（登録トークンを発行の応答を受けた画面にだけ表示する）と REQ-SOURCING-024（詳細に状態、最終接続時刻、実行の件数と失敗を表示する）の追加だけであり、公開 HTTP 契約は変えていない。
トークンは部品の状態にだけ持ち、作成後も遷移しない。無効化の拒否でも表示中のトークンを消す。
保留の承認と破棄、候補の一覧、しきい値の編集の画面は対象外とし、画面は保留の状態と件数だけを表示する。この操作は管理 API に残るので、管理画面だけでは保留を解消できない。
起票時の `affected_spec` の REQ-SOURCING-002 は SCIM の要件で無関係だったため差し替えた。
`CopyableValue` は二つ目の機能が使うので `components/` へ移した。
