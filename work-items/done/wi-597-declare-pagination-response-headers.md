# ページングのレスポンスヘッダーを TypeSpec に宣言する

共通のキーセットページングを使う16操作の200応答に、ページ送りのレスポンスヘッダーを宣言した。
総件数を返す10操作は `PaginationHeaders`、残りの6操作は `PageLinksHeaders` を使う。
空の結果などで省かれる `Link` は任意、常に返る4つの `Pagination-*` は必須の整数とし、本文や実際の HTTP 応答は変えていない。
API ガイドラインの適用状況も現在の宣言に合わせた。

Jobs などのページング方式の改修は wi-596 に残し、実装とヘッダー宣言の自動照合は対象外とした。
固定ベースラインとの既存の互換性差分253件も対象外であり、今回の OpenAPI の変更はヘッダーの追加とその共有モデルに限られる。
