# 作業項目の完了を実装と同じ正式コミットにまとめる

作業項目の完了を実装と同じ正式コミットへ含める手順に変更した。
完了記録は状態、題名と要約だけに縮め、宣言や検査済みの証明を追加保存しない。
全文を保存する別コミットと、新しい記録の全文への履歴案内を廃止した。

`move-work-item` は縮約前に仕様影響の宣言と作業範囲の差分を照合し、失敗時は記録とリンクを変更しない。
完了済みの宣言を復元して照合する処理を外し、完了した範囲の後に加えた変更は従来の宣言検査に残した。
完了後の CI による申告の独立再照合は保証しない。
製品の仕様、契約、テストの検査と既存の完了記録は変えていない。
