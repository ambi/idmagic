# 記録の再生と模倣のテストを、既存の単体テストと重ならないように整理する

四つの外部の相手について、記録の再生と模倣のテストを同じパッケージの既存の単体テストと振る舞いごとに並べ、同じ分岐を二度検査するものを一方へ寄せた。
寄せる先は、一つの応答で足りる分岐なら手書きの関数で応答を返す既存の単体テストとし、仕様の形が意味を持つ再生の往復と、既存のテストにない分岐は残した。

- MCP Gateway：模倣のテストをすべてと、状態コードだけで決まる拒否の再生、受信確認の形を別の再生が固定している待ち受けの停止の再生を削った。空文字列の `nextCursor` は `TestSendCatalogFollowsCursorsAndSendsOnlyTheDeclaredFields` に一ページとして足し、上流の代役がカーソルの欠落と空文字列を区別するようにした。
- SCIM：409 の後の検索、429 の連続、削除の 204 の再生を削り、Group のメンバーの追加の模倣は本文が相手の状態に届くことだけにした。
- トークンエンドポイント：模倣のテストをすべて削り、応答にない更新トークンと有効期間、365 日を超える有効期間を `TestRefreshParsesTokenEndpointOutcomes` に足した。
- OIDC：鍵の選び方の模倣のテストと、使用済みのコードの交換の表明を削った。
- OAuth2 のツール取得はほかに単体テストがないので変えなかった。

削ったテストが固定していた故障を本番コードへ一つずつ注入し、残ったテストが落ちることを確かめた。
トークンエンドポイントでエラー本文のない 5xx を成功と読む故障と、OIDC で 4xx を成功と読む故障は残ったテストで検出されないが、削る前のテストでも検出されなかった（本文の解釈が先に失敗する）。
SCIM の `MalformedCreateResponseFails` と OIDC の `Faults` は一つの応答で足りるが、既存のテストに同じ分岐がないので動かしていない。
模倣を使うテストがなくなった `testing_oauthtwin.Twin` は残した。
規範の差分はない。
