# 作業範囲の特性化テストの検査から、ほかの作業項目のコミットによる変更を除く

`check-spec-impact` が `spec_impact: none` の進行中の作業項目の範囲で数える特性化テストの変更を、着手時点と作業ツリーの一つの比較から、範囲の各コミットの変更とコミットしていない変更の和に変えた。
ほかの作業項目の完了した範囲に属するコミットは、仕様差分と同じく除く。範囲の起点になかった特性化テストは、従来どおり数えない。
コミットごとに比べるので、本文を保った移動の後でほかの項目が本文を変えても、変えたコミットに帰属する。進行中のほかの項目のコミットは免除しない。
これで、`TestCharacterizeGroupImportRowQuota` の移動と書き換えを wi-98584 の責任として拒否していた `main` の失敗がなくなった。
スナップショットの比較に免除を足す案は、移動の後の書き換えを移動元に対応付けられないので採らなかった。範囲の検査の実行時間は従来と同じ程度（`origin/main` からの範囲で約 2 分 20 秒）である。
