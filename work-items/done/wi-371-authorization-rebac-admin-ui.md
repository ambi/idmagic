# 関係ベース細粒度認可 (ReBAC) の管理 UI を管理コンソールへ載せる

`mise run spec-diff` の差分は、REQ-AUTHORIZATION-011〜013 の追加と、`WriteRelationTuples`、`CheckAccess`、`ListAccessibleResources` の宣言の変更である。
追加した要件は、発行前の差分と縮小の警告、タプル一覧の打ち切りの表示、判定の経路と理由の説明を保証する。
3 操作のモデル未登録の応答は、TypeSpec の 422 を REQ-AUTHORIZATION-002 と実装の 404 へ合わせた。
管理コンソールに認可モデル、関係タプル、アクセス判定の 5 経路を追加し、backend の振る舞いは変えていない。

起票時の方針から、差分へ全規則を含め、確認に画面のダイアログを使い、手動確認を E2E へ置き換えた。
循環の検出はサーバーに任せ、発行は確認の直前に最新を読み直すが、同時発行の排他は持たない。
ローダーの結果をコンテナの状態へ写す画面では、キャッシュの先行描画で古い一覧が残るので、整合トークンを `key` に含める。
