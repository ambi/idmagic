# 記憶済みの端末の失効を、契機となるすべてのユースケースが自身の中で担う

REQ-AUTHENTICATION-028 の契機に User の削除の予約を加え、失効理由 `account_disabled` を無効化と削除予約を含む停止として定義した。
Authentication の資格情報変更と全セッションの失効は、端末失効を必須の依存としてユースケース内で行い、サインイン中の TOTP 登録も同じ失効を伴う。
IdManagement の無効化と削除予約は共通の停止処理を使い、再実行でも残った端末と所有 Agent の停止を完了できる。
User を復元しても端末の信頼は戻さない。
HTTP の契機一覧、依存欠落の拒否、WebAuthn 登録、停止の再実行と復元を、それぞれの作用を観測するテストで固定した。
既に削除予約中の User に残る端末の一括修復と、完全削除の匿名化は対象外とした。
