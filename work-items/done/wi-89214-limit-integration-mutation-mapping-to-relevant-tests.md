# 統合モードの変異検査で、対象を実行しないテストの個別計測を避ける

`mise run spec-diff` は main に対する規範仕様差分なしを報告した。
Mutago 2.10.40 を固定し、変異対象と呼び出し側のテストを指定する `test-go-mutation-selected` を追加した。
個別の被覆計測を行わず、同じ ID の一件再実行と構築不能の区別を利用できる。
全体と選択後の ID ごとの判定、呼び出し側だけの検出、選択外の `TestMain` の非実行、基準テストの失敗を検算する fixture を追加した。
Gremlins は構築失敗の分類、Assay は独自 `TestMain` での個別起動と一件指定の不足から採用しなかった。
既存の gomutants の統合モードを維持し、全逆依存の自動的な計測削減、演算子集合の完全な一致、コールド性能の比較は対象外にした。
本番の小さなパッケージの適用確認で残った生存変異は、等価な 6 件と、既存ページングの境界なしと上限 0 を追加で調べる候補 3 件に分け、製品コードとテストは変更しなかった。
