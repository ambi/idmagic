# システムコンソールのテナント画面を一覧、詳細、作成、変更に分ける

REQ-FRONTEND-003 と REQ-FRONTEND-004 を追加した。
システムコンソールのテナント画面を、一覧、作成（`/system/new-tenant`）、読み取り専用の詳細（`/system/tenants/$realm`）、表示名とパスワードポリシーの変更、上限の変更、正規ロケーションの切替に分けた。
各変更画面は一つの API だけを要求し、成功したら通知付きで詳細へ戻って再取得する。
無効化、再開、正規ロケーションの切替は、一覧の行と詳細のどちらからも確認ダイアログを経てから要求する。
管理 API と業務状態は変えていない。

起票時の記録は削除とテナント横断のリソース読出しも含んでいたため、wi-34219 と wi-33063 に分けた。
MFA ステップアップと操作理由は wi-468 に委ね、この記録が作った確認ダイアログへ足す前提とした。
UI 設計の規則に合わせ、行の操作は残して確認を必須にし、上限と正規ロケーションは別の画面にした。
作成画面をテナントの経路の外に置いたのは、realm `new` の詳細と衝突させないためである。
