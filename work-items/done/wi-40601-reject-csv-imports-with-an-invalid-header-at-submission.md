# 見出しが不正な CSV のインポートを、投入の時点で拒否する

`mise run spec-diff -- main` の結果は規範の変更なしであり、実装を既存の REQ-IDMANAGEMENT-004、055、026、029、034 に合わせた。
User、Group、メンバーシップの CSV は、不正な見出しを投入時に 400 と `invalid_header` で拒否し、プレビューのジョブも成果物も残さない。
投入と計画器は同じ CSV リーダーで見出しを検査し、メンバーシップの必須列はスキーマの意図の列から取得する。
User と Group の投入は実効属性スキーマを読み、照会に失敗した場合は保存も投入もしない。
構文の誤り、投入後のスキーマ変更、REQ-IDMANAGEMENT-026 の本文と例の食い違いの解消は対象外とした。
