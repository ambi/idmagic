# 管理画面で、ワークロードアイデンティティの設定を試しながら作れるようにする

発行者の Discovery 文書から issuer と JWKS URI の入力候補を読み込み、確認して適用する支援を追加した。
取得は既存の SSRF 対策を共用し、公開 HTTPS の接続先、issuer の完全一致、本文の上限を検査する。

関連付けの ID と状態を保ってパターンと Agent を部分更新する API と編集画面を追加した。
指定しなかった項目と並行した状態変更を保ち、正式な HTTP 配線から更新イベントを発行する。
管理画面は OAuth2Client に束縛されていない Agent を区別する。

主体の例による一致なし、一つ、複数の試行と、入力中のパターンの一致を、交換と共通の照合で返す。
重なりは近似による警告にとどめ、確認後の保存を許す。
完全な重なり判定による登録拒否と、トークンを貼り付ける検証は対象外とした。
