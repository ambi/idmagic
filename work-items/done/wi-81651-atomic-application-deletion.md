# アプリケーションと関連状態の削除を原子的に確定する

REQ-APPLICATION-018 を追加し、通常の Application と専用の関連状態、使用量を同じ PostgreSQL トランザクションで削除する。
Application とクライアントを固定し、所有者の公開操作でリフレッシュトークン、同意と Agent の資格情報の束縛を削除してから、外部キーの連鎖でプロトコル設定、資格情報、セッション、割り当て、アイコンと個別ポリシーを消す。
使用量も同じ Tx で減算し、削除、減算またはコミットに失敗すると全状態を維持して成功イベントを出さない。
HTTP の後段にあったプロトコル削除を削除境界へ移し、メモリ実行も同じ操作から関連状態を破棄する。
組み込みクライアントの保護を維持し、ロック後の保存状態を再読することで古い関係を削除に使わない。
実 DB の失敗注入、本番構成の組み立て、HTTP とブラウザーの操作で検証する。
Go の検証、静的解析、対象のブラウザー操作は成功し、全体検査の失敗は変更前の文書の表記違反一件である。
