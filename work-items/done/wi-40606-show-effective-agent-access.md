# 誰の代理でどの Agent が何を実行できるかを一覧で確認する

REQ-IDMANAGEMENT-106 と `GetAgentAccessSummary`、表示用の三つの TypeSpec モデルを追加した。
Agent 詳細から、代行を付与した利用者と期限、束縛先のスコープ、最終発行、操作割当と対象範囲、規則の条件と承認と上限、二層のガードレールを読み取り専用で一覧できる。

不足分だけを既存の組み立て地点で合成し、操作割当、規則、ガードレールは既存 API を利用する方式を選んだ。
代行付与は対象 Agent を指定して読み、他テナントの Agent と材料の読み取り失敗を拒否する。
付与と規則の変更を再表示へ反映し、撤回済み、期限切れ、存在しない束縛先、関係の取得上限を区別する。

条件と関係は評価せず、現在の実行許可を保証しないことを画面へ明示した。
権限の変更、全 Agent と全資源の直積、複数の読み取りを同一時点のスナップショットとして保証することは対象外とした。
大量データの応答確認はメモリ構成の無関係な付与 1 万件を対象とし、実環境での負荷試験は行っていない。
API 本文の静的解析の未対応範囲は、実際の HTTP 応答を検査する受け入れテストで補った。
