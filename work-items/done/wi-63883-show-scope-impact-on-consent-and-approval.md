# 資源とスコープに影響度を登録し、同意と承認の画面に示す

REQ-OAUTH2-097、098 を追加し、スコープ、認可詳細の種類、公開ツールの変更度と個人データの扱いを、登録者の申告として管理 API と管理画面から保存する。
変更前後は操作者と対象を付けて監査に残し、未登録と `personal_data: false` を区別する。
同意、Agent への付与前、本人の承認で各権限の影響度を示し、未登録は取り消せない変更と同じ注意を促す。
同名スコープは有効な登録から保守的に集約し、対象ツールは起票時の識別子で照合する。
既存操作の要件と TypeSpec、UI の宣言を同期し、保存先の共有契約、管理から表示までの HTTP 試験、UI 試験と対象のブラウザー試験で検査する。
Poppy の公開配置、影響度による自動判断と認証水準の変更、部分的なスコープ選択は対象外である。
