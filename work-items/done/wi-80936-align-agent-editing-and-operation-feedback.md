# エージェントの編集と保存結果を作業の単位で揃える

`mise run spec-diff -- main` は規範仕様の差分なしを報告した。
UI 設計に編集と確定の単位、保存成功後の詳細への復帰、失敗時の入力保持、即時操作とキャンセルの違いを定めた。
エージェントの基本情報、ガードレール、資格情報を別の作業に分け、確定した設定を詳細で再取得し、成功通知を戻り先で一度だけ表示する。
Alert の種類を型で必須にし、指定漏れを許す変更は型検査の負例で拒否する。
UI ガイドラインを文脈導出の直接参照に追加したが、読了の証明とは扱わず、通知の role、保存とキャンセル、遷移後の再取得、資格情報の操作を実行するテストで確かめる。
既存の誤った通知は文言だけのテストを通っていたため、成功の status とエラーの alert を独立に表明する回帰を残した。
