# 対象とエージェントを選んでアクセス権を管理する

`spec-diff main` が示す REQ-AUTHORIZATION-014 と REQ-IDMANAGEMENT-104 を追加した。
日常の Agent への直接付与を、接続先、権限、対象 ID、名前による Agent の選択へまとめ、同じ関係データの一覧と取消を提供した。
モデル、複雑な関係と判定の調査は開発者向け設定へ分け、接続先を越える適用範囲と実効許可ではないことを明示した。
認証用クライアントを新規作成と既存利用の選択式にし、作成済み ID、束縛の成否、部分失敗からの再試行を示した。
残る ID にはコピーを付け、クリップボードの失敗を成功と表示しないようにした。
デモを新しい付与経路へ更新し、Okta 風と Ping 風の公式資料に基づく概念比較を加えた。
外部カタログの取得、競合実機との計測、任意モデルの付与、承認条件の変更と実効アクセス一覧は対象外とした。
UI の全検証とデモの実行、取消、停止、既存資格情報の束縛と解除を実ブラウザーで検証した。
