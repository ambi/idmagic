# mise.toml の変更では、変わったタスクを呼ぶ層だけを検証する

`verify-changed` と `verify-integration` で `mise.toml` の変更前後を比較し、タスクだけの変更では検査の閉包が届く層と `check` を選ぶようにした。
タスク以外の変更と読み取り失敗は全層へ戻し、Go のタスク変更は全パッケージを選ぶ。
`spec-diff` で規範仕様の変更がないことを確認した。

閉包の解釈は既存の `taskClosure` を使い、コマンド文字列から実行内容を推測する処理は対象外とした。
変更前の閉包の省略は、依存辺の変更タスク自体が残る閉包から到達できるため等価と判断し、全層へのフォールバックと CLI の配線を独立した故障として検査した。
未実施事項はない。
