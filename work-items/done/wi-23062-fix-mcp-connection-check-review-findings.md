# MCP 接続の確認が、不足ごとに直せる修正先を示し、不完全な材料で割当の不足を断定しない

REQ-OAUTH2-094 を是正した。不足ごとの修正先を表で定め、テナントのデフォルトのガードレールの拒否には管理 API を示すようにした。ガードレールの拒否の条件も表で定め、違反時の扱いの省略は `deny` とし、`require_approval` は不足に数えないと明記した。操作の関係が取得の上限に達したときは割当を確かめられないことを示し、カタログの取得の失敗は他の表示を止めないとした。HTTP 契約は変えていない。

実装は、ガードレールの不足を層と種類の組で区別し、画面のリンク先をテストで固定した。loader は再認証を要する失敗を投げ直す。到達を要する確認は wi-38469 の対象範囲へ移し、wi-85145 の要約と wi-38469 の記述を合わせた。
