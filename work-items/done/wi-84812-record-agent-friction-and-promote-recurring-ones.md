# エージェントが作業中に受けた妨げをコミットに残し、繰り返したものを指示と検査へ昇格させる

`mise run spec-diff` は main に対する規範仕様の変更がないと報告した。
エージェントが作業中に受けた妨げを、正式コミットの `Agent-Friction: <対象> — <起きたこと>` トレーラーに残す規則を `agent-guidance.md` に定め、`implement-work-item` と `new-work-item` のコミット前に振り返る手順を足した。
`mise run report-agent-friction` は `git log` のトレーラーを対象（パスとアンカー、または `mise run <task>`）ごとに数え、2 件以上、1 件、現在のツリーにない対象、形式外の値に分けて示す。ゲートにはしない。
記録の置き場所には、並列の worktree で衝突せず rebase でも残るトレーラーを選び、台帳ファイル、妨げごとの作業項目、個人メモリは採らなかった。
集計の後の手順を `review-agent-friction` skill にし、原因ごとの扱い（検査への昇格、文書の修正、読まれる節への移動、何もしない）を `agent-guidance.md` の表に定めた。採否は利用者が決め、採った変更は作業項目として起票し、集計から指示を直接書き換えない。
判断した対象は振り返りのコミットに `Agent-Friction-Reviewed: <対象>` を一件ずつ書き、集計はその対象のそれより前の記録を数えない。振り返りの位置を一つの境界にする案は、判断しなかった 1 件だけの記録まで消して 2 件に届かなくなるので採らなかった。
過去のコミットにはトレーラーがないので、集計は空から始まる。
