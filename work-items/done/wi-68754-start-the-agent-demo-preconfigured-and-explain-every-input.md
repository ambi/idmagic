# AI エージェントのデモを設定済みで始められるようにし、残る入力の意味と出所を示す

デモに「設定済みで始める」と「自分で設定する」の二つの入口を設けた。
設定済みの入口は、管理者が入力した資格情報で管理画面と同じ認可コードフローでログインし、管理 API で通常の管理と同じ設定を作って接続する。作ったものは出所付きの一覧で示し、管理画面へのリンクを付ける。管理 API トークンでは操作の割当を作れないため、この方式にした。
自分で設定する手順は 4 つで、各値に出所の印を付け、必須の手順、決める値、写す値の数を表示し、E2E で固定した。通常と文書ごとの二択はやめ、「文書ごとに絞る」を追加の手順にした。
手引きに Okta と Ping の公式手順との必須の作業の比較を加えた。製品の要件、契約、DB は変えていない。写す 3 値の自動の受け渡しは、配置の手間を隠さないため対象外とした。
