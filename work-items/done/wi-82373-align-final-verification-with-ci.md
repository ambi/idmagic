# 手元の全 E2E を増やさず CI の失敗を早く検出する

規範仕様の意味上の変更はない。
利用者との協議で、全 E2E を手元の完了前に義務付ける案と専用の最終検証入口を取りやめ、既存の局所検証と CI を維持した。
繰り返し発生したナビゲーションのずれは、E2E と DOM テストで独立した期待値と操作スクリプトを共有し、実コンポーネントの日本語と英語、領域の開閉、遷移先をブラウザーの起動なしで検査する形にした。
作業項目の完了処理には既存の用語検査を接続し、文書の最終編集で混入した禁止表記を移動前に拒否する。
実ブラウザー固有の問題と全体への影響は引き続き CI が検証し、失敗率全体の改善量は未計測である。
