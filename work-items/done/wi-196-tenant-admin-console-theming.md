# テナントブランディングを管理コンソール全体のテーマへ適用する

REQ-TENANCY-004 と TypeSpec の TenantBranding、GetTenantBranding の適用先をテナント管理コンソールへ拡張し、REQ-FRONTEND-005 に配色、取得失敗時の継続、realm の分離、システム画面への非適用を定めた。
管理ルートに閉じたテーマをシェルとポータルへ渡し、ロゴと製品名、主要操作、見出し、選択、リンク、focus へ反映する。
設定画面の保存結果は直ちに反映し、古い取得応答による上書きを防ぐ。

任意の形式正しい色に対して黒または白の前景色を自動選択し、明色面のリンクと見出しには安全な色を使う。
成功、警告、危険の意味色は維持する。
永続データの移行と新しい依存は不要であり、表示の変更は revert で戻せる。

独立した色の検算、遅延応答を含む realm 切替、取得失敗、システム画面の分離を単体検査で扱い、ブラウザーでは代表 3 画面、モバイルのメニュー、キーボード focus、保存直後の反映、ロゴ配信を確認した。
全件の UI E2E と全画面の画像比較、二つの realm を手動で切り替える確認は実施せず、変更に合う対象 E2E と応答順を制御した単体検査を選んだ。
システムコンソールへのテーマ適用、任意の CSS、レイアウトとフォントの変更は対象外である。
