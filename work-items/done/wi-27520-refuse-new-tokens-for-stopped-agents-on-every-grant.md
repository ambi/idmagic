# 止めた Agent のクライアントには、どのグラントでも新しいトークンを発行しない

REQ-OAUTH2-046 の対象を `client_credentials` からすべてのグラントへ広げ、Agent が `Disabled` または `Killed`、所有者が非 Active または解決不能なら、401 と `invalid_client` で新規発行を拒否する仕様にした。
グラント分岐前で Agent と所有者を一度解決し、同じ Agent を発行時の記録と `client_credentials` の承認区分判定に使う。
TypeSpec は既存の `InvalidClientError` を使い、承認の要否と発行済みトークンの失効は従来の規則を維持する。

有効な認可コード、実際に発行したリフレッシュトークン、承認済みデバイスコードについて、停止前の成功、停止後の拒否、資格情報と Agent の無変更、発行イベントの無発行、再有効化後の同じ資格情報での成功を検査するテストを加えた。
全8グラントについて分岐前の拒否も独立に検査する。
状態確認と署名の間の並行停止を原子的にすることは対象外であり、発行済みトークンの失効は引き続き REQ-OAUTH2-012 に依存する。
