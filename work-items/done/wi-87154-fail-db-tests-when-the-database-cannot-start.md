# DB を起動できないとき、DB を使うテストを Skip ではなく失敗にする

製品の規範仕様は変更していない。
DB 初期化に失敗した場合は `Require` を呼ぶテストをデフォルトで失敗にし、DB を使わないテストは続行する。
`PGTEST_ALLOW_SKIP=1` の場合だけ Skip を許し、許可の変更を Go の結果キャッシュが追跡できるようテスト内で環境を読む。

実行器もデフォルトで DB 未検証を拒否し、Skip を許した実行は未検証として報告する。
CI の `VERIFICATION_REQUIRE_DB=1` は許可の混入や未実行を拒否するために残し、子プロセス用の `testdata/` は全体の DB 棚卸しから除く。
環境変数の読み取り規則には既存の本番到達性判定を使い、テスト専用支援を許可し、本番から参照される場合の拒否を保つ。

DB 起動そのものの改善と、DB を使わないテストの Skip の扱いは対象外とした。
