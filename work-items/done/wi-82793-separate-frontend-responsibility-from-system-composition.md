# フロントエンドの責務を System の組み立て地点から分ける

規範仕様の差分はない。
Frontend を公開 HTTP 契約で接続するモジュールとして宣言し、System の組み立て地点をバックエンドの結線へ限定した。
画面の表示言語、ホステッド UI、ポータルの OIDC RP と用語を Frontend へ移し、既存の要件 ID、例、要件文を維持した。
認可トランザクションの保持、バックエンドの英語エラー、画面と API が協調する経路の保証は System に残した。
責務表の実装パスは非 Go モジュールも表し、HTTP モジュールによる Go の実装と公開パッケージの宣言、System への非 Go 実装の混入を拒否する。
過去のヘッダー、Go の公開範囲、未宣言と重複の拒否、移動した仕様の EARS 検査を維持した。
画面の再設計、URL と公開 API の変更、独立したリリース系列の保証は対象外とした。
製品コードを変えていないため、Go の race と mutation、ブラウザー E2E は実行していない。
今回の対象に未実施事項はない。
