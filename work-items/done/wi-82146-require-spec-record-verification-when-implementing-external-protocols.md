# 外部の標準や製品への対応を実装するときに、一次資料の例による検証を同じ作業項目で行うと定める

テスト方針の外部契約と設定の利用に、一次資料の例による検証を作る時期、対象、既存の単体テストとの分担を書き足した。
外部の標準や製品への対応を新しく実装する作業と、対応するバージョンを上げる作業では、同じ作業項目で実装の前に記録（送る側）または一次資料の要求の例による受け入れの検査（受ける側）を作る。
再生は仕様の形が意味を持つ往復に絞り、状態コードだけで決まる往復は既存の単体テストに任せる。
模倣は状態をまたぐ検査を既存のテストが扱えないときだけ置く。
一次資料に例がない相手は、費用と見つけられる故障を比べて採否を決める。
外部制約と利用側の成立からこの規則へリンクした。
規範の差分はない。
