# 生成した文書サイトのナビゲーションと、開発文書とフォーマット文書の構成を整える

`spec-diff` の比較では、ブランチ点に対する規範の差分はない。
生成サイトのサイドバーで、子のない枝を葉にして字下げをそろえ、機能の段の名札を「機能」にし、モジュールを責務表の順に並べた。
例の付録は機能のページの末尾の節「例」として組み込み、例の子のページをなくした。付録へのリンクはその節へ届く。
コードブロックは生成時に highlight.js で色を付け、bash では外部コマンドの名前にも印を付ける。
`format-rationale.md` を廃止し、「全体の方針」の表だけを文書ガイドへ移した。
テストの判定基準（race 検査、作用の観測、プロパティテスト、ミューテーションテスト）は `testing.md` へ一本化し、ワークフローの節を「検証の進め方」に絞った。
文書ガイドは 790 行から 410 行へ縮めた。フォーマット文書と開発文書の節番号を外し、句点付きの太字の小見出しを見出しに改めた。仕様フォーマットの「旧形式の扱い」は削った。
標準仕様に任意の最初の節 `## 標準と製品の関係` を設け、WsFederation の標準仕様に、標準と Microsoft の製品の組み合わせのまとめを置いた。
