# 最初の実装の時点で、後からリファクタリングと bugfix の項目が要る問題を減らす

2026-10-10 から 11-06 までの作業項目で、後から直すことになった形を記録して原因を分類し、対策の効果を評価して観察を打ち切った。
規範仕様の差分はない。
後から直す項目を実際に減らしたのは、機械の検査と、一つの原因に絞った一斉の棚卸しだった。

設計ガイドライン、テスト方針、実装スキルへ足した文章の規則には効果の証拠がない。
案 3、6、12 は、採用の後に同じ形が再び入った（wi-41012 → wi-85215、wi-91126、wi-53317 → wi-94860）。
規則は、変更する人が自分の変更を条件に当たると判断しなければ働かないため、文言を広げる改訂は採らなかった。
