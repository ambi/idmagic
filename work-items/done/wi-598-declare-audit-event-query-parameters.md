# 監査イベントの絞り込み条件を個別のクエリパラメーターとして宣言する

監査イベントの検索、同期エクスポートと非同期エクスポートの開始の6操作で、単一の `query` を廃し、共有の `AuditEventQuery` から10個の任意クエリパラメーターを展開した。
`filter` はオブジェクト配列から文字列配列へ改め、`field:operator:value[,value2]` を同名のパラメーターで繰り返す現行の通信形式を宣言した。
生成 OpenAPI の契約テストで6操作の名前、型、任意性、配列の符号化とボディの不在を検査し、API ガイドラインの適用状況を更新した。
フロントエンドは生成クエリ型を使わず、既存の送信処理がこの形式に一致するため編集していない。
条件の追加とサーバーの検索処理の変更は対象外とした。
初回公開前の保存済みベースラインとの比較は今回の `query` 削除を含む253件の差分を報告するが、公開状態に応じた互換性ゲートでは公開済み契約がないものとして扱う。
