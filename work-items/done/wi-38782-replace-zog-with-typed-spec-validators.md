# Zog を shared/spec の型付き検証関数へ置き換える

バックエンドの検証ライブラリ Zog をやめ、`shared/spec` の型付きの規則（`Rule[T]` と `Required`、`Optional` などのフィールド関数、`All`）へ全 27 ファイルを移した。
フィールド名の文字列とリフレクションをなくし、名前と型の誤りをコンパイル時に検出する。
Zog のゼロ値の扱い、違反の集め方、エラーの文言と wire 名、長さの違反だけを 422 にする区別を保った。
`spec-diff` は規範仕様の差分なしを示す。
受理範囲はメールアドレスと識別子の二つを TOBE で決め直した。
メールアドレスは書式の定めがなかったので、値オブジェクトに RFC 5322 と RFC 6532 の addr-spec として定め、国際化アドレスも受理する。
識別子は API ガイドラインどおり UUID バージョン 4 の正規形だけを受理する。
`backend.md` に値の検証の節を加え、規則の種類と意味を実装の名前なしで定めた。
