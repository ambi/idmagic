# Entra Connect に合わせる ImmutableID の設定を通常の導入手順で理解できるようにする

REQ-WSFEDERATION-001 に、通常操作で組み込み属性を使い、既存構成の属性を編集と別ドメインの追加でも保持すること、保存先の変更を明示的な詳細設定に分けることを追加した。
画面と導入手順に Entra Connect の選択確認、Connector の対応付け、完全な再同期、Graph の実値との比較を加え、欠損と不正値の拒否では対象ユーザーと直す保存先を示す。
同期側の属性を推測で自動選択せず、GUID の生バイトの Base64 を比較する。Connector のデフォルト、API の明示指定、一意性と本人の編集禁止、既存ユーザーの値は変えない。
通常設定と独自属性の保持、拒否時の案内をブラウザーで検証し、既存の WS-Federation の制約と二つの AD 属性の変換も確認した。実際の AD と Entra 間の値の照合は運用時に行う。
