# 変異テストのツールを gomutants から gamut へ置き換える

規範仕様の変更はない。
変異テストの固定ツールを gamut 0.1.0 へ替え、通常実行、1 件再実行、差分モード、統合モードと canary の検算を移行した。
タスクの引数の順序と意味、5 種類の演算子、デフォルトのキャッシュ無効を保ち、報告の検査を mutation-testing-elements の形式へ合わせた。
テスト方針へ実行方式、状態名、統合モードの準備費用を反映し、gomutants の schemata を待っていた wi-49807 を中止した。
変異 ID は旧ツールと互換性がなく、過去の報告は位置、演算子、置換内容で突き合わせる。
演算子の拡張とキャッシュのデフォルト有効化は対象外とし、依存の変更後のキャッシュ再利用は未検証のまま残す。
