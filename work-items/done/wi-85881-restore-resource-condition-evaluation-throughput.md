# 条件を持つリソースアクセス評価を局所測定の処理量の目標へ戻す

CEL v0.33.1 の Pratt パーサーを既存の型検査、AST 検証器とプログラム構築へ接続し、キャッシュを加えずに条件付き評価の局所性能目標を満たした。
`spec-diff` では規範差分がなく、1024 コードポイントの受理範囲、評価の意味、条件変更の即時反映、保存値と監査イベントを維持した。
再帰の数え方に差があるため、深くなり得る式と Pratt が構文を拒否した式は従来の解析へ戻す。
互換性の差分検査、並行評価の race 検査、30 秒の差分 fuzz 探索、両保存構成の条件変更・削除と監査の追従を確認した。
正式な HTTP の全 18 ケースが 500 件/秒以上、p99 100 ms 以下と全応答の正しさを満たし、PostgreSQL の日本語条件は約 203 件/秒から約 1,542 件/秒、内包は約 390 件/秒から約 671 件/秒へ改善した。
初回・反復のコンパイル、評価だけと通常判定の測定を性能設計へ残した。
本番の混合負荷と長時間のキャパシティ、任意の正規表現の最悪費用やメモリ上限は対象外とし、局所測定の成功からは保証しない。
