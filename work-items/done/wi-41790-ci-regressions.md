# CI で再現したキャッシュ検査とブラウザー操作の失敗を修復する

CI run 41170532723 のキャッシュ検査は、親の `GOFLAGS=-count=1` の継承で自分の前提を壊していた。キャッシュの意味を試す子だけ標準の Go フラグへ固定する。
セッション一覧と失効の認証が Bearer と Cookie で食い違っていたため、画面の一覧も Cookie で取得する。認証器リセットの画面は、自身のリセットで失効するトークンによる再取得に依存せず、成功応答の MFA 状態を表示する。
利用者の選択に従い REQ-AUTHENTICATION-013、REQ-AUTHENTICATION-021、REQ-SHAREDSIGNALS-012 を整合させ、個別失効と現在以外の一括失効を User 全体へ広げない。SessionEnded.allSessions で管理者の全失効を区別し、資格情報変更や User 全体の停止による全体失効は維持する。
見逃しの原因だった対象外状態、Bearer と Cookie の併存、成功直後にトークンが失効する条件を、局所的な回帰検査へ加えた。イベントの直列化後の表現も照合し、全 E2E や CodeQL を通常の編集ごとに課す規則は増やしていない。
個別失効のアクセストークンは既存契約どおり短い TTL に任せ、対象 sid のリフレッシュトークンを即時に失効する。追加の永続表とデータ移行はない。
