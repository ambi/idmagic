# 管理 API からの Group の CSV エクスポートでテナント定義の属性の列を選べるようにする

管理 API の Group エクスポートの開始に既存の Group CSV エクスポーターとテナント属性スキーマの読み取りを配線し、定義済みの `custom:<key>` を受け付けるようにした。
作業開始時のコミットを基準にした `spec-diff` では規範差分はなく、REQ-IDMANAGEMENT-027 と既存の TypeSpec に実装を適合させた。
正式な HTTP の組み立てから選択列を保持したジョブとイベント、未定義、他テナント限定、重複、秘密の列の拒否と無作用を観測するテストを加えた。
検証器と属性スキーマの参照を個別に外す故障を、成功経路のテストが検出することを確かめた。
User とメンバーシップの列、worker、保存方式は変更せず、新しい受け入れテストは開始に限定し、CSV の往復は既存の Group テストで検証した。
