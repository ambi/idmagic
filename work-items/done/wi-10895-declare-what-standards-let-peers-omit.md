# 標準の宣言に、相手が省略または追加できる要素の受け入れを書かせる

標準仕様の規則に三つを足した。
製品が標準を受ける側なら、相手が省略、追加、別の形にできる要素の受け入れを行にする。
採用した標準が依存し、受け入れや検査に規則を課す土台の標準も宣言する。
受け入れの行を引く試験は、相手が省略または追加した形の要求を入口へ送る。

判断：`Adoption` と `Strength` の列は変えず、列や機械の検査も足していない。受け入れの行も「製品が実行すること」として既存の列で表せるためである。機械で見分ける必要があるかは、棚卸し（wi-77372）で行の数と形が分かってから決める。
例は wi-62545 で加えた `RFC7521-CLIENT-ID-OPTIONAL` に揃えた。既存の宣言には遡って適用していない。
