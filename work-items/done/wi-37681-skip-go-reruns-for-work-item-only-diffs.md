# 検証済みの revision からの差分が作業記録だけなら、Go 検査を再実行しない判断を示す

規範仕様の変更はない。
必要な Go 検査が成功したクリーンな revision からの追跡差分と未追跡ファイルが `work-items/` に限られる場合に、再実行しない判断の条件と確認手順を開発ワークフローへ記した。
移動元を見落とさないよう差分の列挙では `--no-renames` を指定し、条件を確かめられない場合や入力、実行条件に変化がある場合は該当する検査を再実行する。
`report-verification` の `stale` 表示を保ったまま、この判断ができることをテスト方針へ記した。
検証ツール、レポート形式、mise タスク、CI の必須検査と、ほかの文書だけの差分への適用は対象外とした。
