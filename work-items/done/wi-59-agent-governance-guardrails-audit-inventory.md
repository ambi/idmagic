# 所有者不在、休眠、未束縛の Agent を棚卸しで一覧する

REQ-IDMANAGEMENT-094 と `ListAgentInventory` を加え、Agent ごとの所有者の状態、最終のトークン発行時刻、存在しない束縛先と、`owner_missing`、`dormant`、`unbound` の所見を返すようにした。
`AccessTokenIssued` に任意の `agentId` を加え、最終発行は監査の検索属性 `agent.id` から読む。棚卸しは状態を持たず、新しい表、カーソル、ジョブを作らない。
ガードレールは 2026-10-30 の判断で wi-30707 へ分けた。wi-184 の `event_logs` は現行のスキーマに無いので、起票時の「イベントログからの投影」は監査の検索属性の読み取りに置き換えた。
起票時の「専用の権限」は採らず、`agents:read` を使う。

残る制約は次のとおりである。
認可コード、リフレッシュ、デバイスコードの発行は `agentId` を載せないので、これらだけで使う Agent は休眠と判定される。
休眠の日数は監査の保持期間（365 日）を超えられず、保持期間の方針を変えるなら上限も見直す。
棚卸しはページングせず全件を読むので、Agent の多いテナントでは応答が重くなる。
ブラウザーを通す UI の E2E は追加も実行もしていない。
