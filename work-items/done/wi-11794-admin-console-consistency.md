# 管理コンソールの一覧、フォームとナビゲーションを揃える

REQ-FRONTEND-001、002 を追加し、一覧の総数と表示件数、更新操作、専用の追加画面を揃えた。
サイドバーを用途でグループ化し、エージェントの「外部 API の代理実行」とディレクトリ同期を区別した。
フォームを広げて関連項目を2列にし、必須・任意表示と削除などの確認を共通化した。
属性スキーマの一覧内編集、ダッシュボードの集計と発行直後の資格情報表示は、用途に合う差として残した。
REQ-APITOKENS-001 の配置を専用画面へ変更し、REQ-APITOKENS-005 と本人向け API 3本、スコープの型を追加した。
個人用トークンは所属テナントの本人の記録に限定し、発行は再認証と account スコープに制限する。
カスタムロールの追加と既存の管理発行トークンの主体変更は対象外とした。
