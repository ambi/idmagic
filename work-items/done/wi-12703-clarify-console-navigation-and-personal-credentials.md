# 管理コンソールの移動と資格情報の主体を分かりやすくする

REQ-APITOKENS-001 に、発行前にログイン中の本人と操作対象テナントを区別して表示する要件を追加した。
管理コンソールでの発行を維持し、全件一覧と「自分のトークンを発行」を区別する。
サイドバーは現在の領域だけを展開し、ほかの領域はホバー、クリックとキーボードで開く横のメニューから移動する。
全展開とピン留めは採用しない。
CSV インポートのアイコンを統一し、組み込み属性の表示名を日本語と英語の辞書で表示する。
ユーザー編集、詳細、本人のプロフィール、属性カタログとエクスポート列に適用し、カスタム属性の表示名と送信キーは維持する。
