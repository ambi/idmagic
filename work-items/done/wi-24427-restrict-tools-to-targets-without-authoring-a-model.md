# 対象ごとの権限を、モデルの作成なしに操作の割当から設定する

REQ-OAUTH2-083、REQ-OAUTH2-064、REQ-AUTHORIZATION-002、016、017 を更新した。
組み込みの型 `idmagic_mcp_operation` で対象引数を持つツールは、操作の割当に加えて、全対象の `invoke_any_target` か、`<登録 ID>/<操作の識別子>/<対象 ID>` の `invoke` を要求する。範囲のない割当はどの対象も許可しない。
範囲は割当と同じ組み込みの型の関係で表し、利用者のモデル、新しいテーブル、モジュール間の依存を足さなかった。従来の型と関係を持つ規則は従来の判定を保つ。
Agent の利用する接続先の編集で「すべての対象」と「指定した対象だけ」を選び、操作と範囲を一つの差分で保存する。接続先の編集のチェックは組み込みの型のまま対象引数を持たせ、型と関係の入力を求めない。
接続先の対象の画面からの編集は、外部の対象カタログがないため対象外とした。デモの文書ごとの例の置き換えは wi-68754 へ移した。
