# 利用者の削除でも consents のクォータの枠を空ける

`spec-diff` の差分は REQ-IDMANAGEMENT-050 の変更である。
User の完全削除は、消した同意と Agent への代行のうち撤回していない行（期限切れを含む）の件数だけ `consents` の使用量を減らす。撤回した行は撤回の時点で減算済みなので数えない。
同意の保存先の `DeleteAllForSub` が削除と同じ文で件数を返す形にし、Application の削除の前例と揃えた。削除の前に数える形は、その間の付与で件数がずれるので採らなかった。
減算は同意の削除の直後に行う。削除が確定した後に減算が失敗すると、再実行の削除は 0 件を返すのでその分の枠は戻らない。完全削除を保存先ごとに確定する設計の残りのずれとして扱い、削除と減算を同じトランザクションにする変更は採らなかった。
既存のテナントでずれた使用量の補正は対象外である。
