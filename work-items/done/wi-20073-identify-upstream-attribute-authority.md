# 属性の出どころと上流の書き込み範囲を識別する

属性定義に `write_authority` を追加し、User と値の有無によらず上流の書き込み範囲を分類できるようにした。
省略と既存の定義は `upstream` とし、管理者が明示した `local` のカスタム属性への取り込みと JIT の追加、変更と削除を、使用量、保存、所属の再評価と通知の前に拒否する。
同値のローカル属性の保持は許し、動的規則が参照する属性の分類変更を既存の参照保護へ加えた。

仕様差分は REQ-IDMANAGEMENT-091 の追加、REQ-IDMANAGEMENT-001 と REQ-TENANCY-043 の変更、属性定義とスキーマ更新の TypeSpec の拡張である。
メモリと PostgreSQL に同じ保存契約を適用し、作成、更新、JIT と参照保護を迂回させる四つの故障をテストが検出することを確認した。
値ごとの来歴の復元、ロール付与の制限と直接所属の制限は含めず、後二者は wi-428 へ残す。
