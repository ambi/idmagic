# 本人による同意の撤回でも consents のクォータの枠を空ける

本人による同意の撤回でも、`Granted` からの遷移で `consents` の使用量を 1 減らすようにした。
REQ-OAUTH2-032 に、減算と、`Granted` ではない同意の撤回では使用量を変えないことを追加した。
製品の撤回の経路は起票時に想定した `Module.AccountConsents` ではなく `handlers_http` の `Deps.accountConsents` だったので、両方へ保存先を渡した。
二度目の撤回のテストは修正前でも成功するので、`Granted` の分岐を外す故障を注入して検出できることを確かめた。
利用者の削除でも同じずれがあるので、wi-51164 として起票した。
REQ-OAUTH2-031 に管理者の撤回の減算の記述がないことは、振る舞いを変えないので対象外とした。
