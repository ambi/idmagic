# デモの閲覧固定を外し、作成・更新と削除を個別に許可する

デモの MCP サーバーに `write_document` を追加し、閲覧、作成・更新、削除の三つのツールを試せるようにした。
カタログを使う通常の例は発行スコープを省略し、IdMagic が現在の割当と認証上限から決める。文書別の例は従来どおり `tools:read` を明示する。
閲覧は `tools:read`、作成・更新と削除は同じ `tools:write` へ対応させ、操作は一つずつ割り当てる。同じスコープでも未割当の削除は拒否される。
新しいスコープが要る割当の後は「トークンを取り直す」で再発行し、同じスコープ内の追加と取消は次の依頼へ反映される。
製品の要件、公開 TypeSpec、モジュール境界、DB は変えていない。デモの手順数と転記は増やしていないが、ツール名と各行のスコープの手入力は増えた。その削減は wi-95247 で扱う。
