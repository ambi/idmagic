# クライアント登録で既存のグラント型を受け付ける

`mise run spec-diff -- main` は規範仕様の差分なしを報告した。
クライアント登録の HTTP 入力に残っていた四種類の独自の許可リストを `GrantType.Valid` に統一し、既存の CIBA、Token Exchange、JWT のグラントを登録できるようにした。
デモと同じ要求を管理 API から登録する回帰テストと、公開契約の八種類の受理、未知のグラントの拒否を検証するテストを残した。
CIBA のテストとデモの初期データは登録 API を経ずにクライアントを準備しており、利用前の登録で拒否される故障を検出していなかった。
デモ手順の管理 API の補助関数は、失敗時の本文を標準エラーへ出し、変数への代入中も原因が見えるようにした。
