# minimatch の脆弱性を修正し依存変更時の監査を手元で選ぶ

minimatch の GHSA-g3hv-75wg-m249（Code scanning #69）に対し、開発用の推移依存を修正版 11.0.1 に固定した。
手元の見逃しには `verify-changed` が既存の依存監査を選ばない欠落があったため、依存定義、lockfile、監査設定と監査タスクの変更だけで既存の `audit-dependencies` を選ぶようにした。
通常のコード変更にネットワーク監査を追加せず、統合では両側の依存変更が重なるときだけ再検査する。
新しい脆弱性が公開された場合の検知は引き続き CI の毎回の監査が担う。製品の API、保存状態、認証規則の変更はない。
