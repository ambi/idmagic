# 層名パッケージの import 別名を `importas` で正準化する

`domain`、`ports`、`usecases` の import 別名を揃え、`importas` で別名なしも拒否する。
既存の略称と衝突回避を明示規則で保持し、新しいパッケージには `internal` を所有名に含めない正規表現を適用する。
特性化テストの検査器は import の参照先を用いて別名追従だけを許可し、期待値、操作、参照先の変更と曖昧な束縛は従来どおり拒否する。
規範仕様の差分はなく、製品の振る舞い、契約、パッケージ配置と公開範囲は変えない。
