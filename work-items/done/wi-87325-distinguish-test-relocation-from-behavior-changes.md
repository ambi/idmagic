# テストの移動と参照の追従だけで、構造変更へ追加の RED を要求しない

`mise run spec-diff` に製品規範の差分はない。
起票後の wi-38309 で RED 記録と免除判定が廃止されていたため、利用者の選択に従い文書修正として完了した。
Git 差分の自動分類器、その診断、新規テストと故障注入は対象外とし、判定基準を開発ワークフローへ集約した。
仕様影響のない refactor では、同一内容の移動と対応を確認できる Go の参照追従だけなら追加の RED を求めず、期待値、入力、表明、skip、実行対象、fixture などの変更と、不明な変更が混じる場合は従来の証拠を求める。
移動後の既存テスト、配置、契約、逆依存の検査は維持し、作業項目形式からも同じ基準を参照する。
`8d93090d` の Authorization の同一内容の移動と import 追従は対象となる差分の例だが、同コミット全体は新規テストも含むため免除しない。
Go 以外の参照追従は認めず、製品コードが振る舞いを保つことの静的な証明は行わない。
