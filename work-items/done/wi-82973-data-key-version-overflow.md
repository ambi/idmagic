# DEK のバージョンの切り詰めによる別の鍵へのアクセスを防ぐ

Code scanning #71、#72 は実際の欠陥だった。DEK の版を無検査で int32 に変換し、存在しない大きな版が別の鍵へ折り返していた。
PostgreSQL の検索、無効化、破棄で範囲を検査し、存在しない版として拒否する。既存のライフサイクル仕様と HTTP 契約へ実装を合わせ、規範の追加はない。
「小さいカウンター」という理由で抑止していた引数には外部入力も入っていたため、抑止を除去した。回帰検査は正負の折り返しと上限を使い、対象外の鍵の状態と素材も読む。
SSRF の #73 は接続時の公開 IP 検査、プロキシ無効化、リダイレクト拒否が効くため誤検知と判断した。#70 の伝播元 SecretKeyVersion は秘密値でなく整数の版番号で、状態拒否のエラーも版と状態だけを含む。GitHub 上のアラート状態は変更していない。
