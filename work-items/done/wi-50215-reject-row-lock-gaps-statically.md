# 読んだ後の守りのない書き込みを静的検査で拒否し、見つかった欠陥を直す

`spec-diff` の差分は REQ-DATAKEYS-002 の変更で、再暗号化が読んだ後に変わった値を書き戻さないことを追加した。REQ-SAML-004 は文を変えず、同時の作成でも満たすように実装を直した。
`mise run check-sql-concurrency` は、行のない経路の挿入、ロックなしで読んだテーブルへの無条件の書き込み、トランザクションの外の `FOR UPDATE` を拒否する。修正前のレート制限と、SAML と再暗号化の欠陥を検出することを確かめた。
TOTP と上流 IdP の `ReencryptBatch` は、再登録されたシードや入れ替えられたシークレットを古い値で書き戻していた。読んだ値のままの行だけを更新する形に直した。
確認の限界として、検査はテキストの照合であり、対象外に挙げた形は検出しない。並行処理の正しさは保証しない。
