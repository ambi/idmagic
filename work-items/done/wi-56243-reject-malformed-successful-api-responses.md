# API の成功応答の壊れた本文を空のオブジェクトとして扱わない

REQ-SYSTEM-031 を追加し、画面が呼んだ API の成功応答のうち、204、205、`Content-Length: 0` を本文のない成功とし、JSON として読めない本文を取得または操作の失敗として表示するようにした。
API 共通処理は、成功応答の解析失敗を `{}` に置き換えず、REQ-SYSTEM-011 の代わりの文を持つエラーを投げる。失敗応答の読めない本文は従来どおり代わりの文へ落とす。
本文のない成功の値は `{}` から `undefined` に変わった。`request` を通る 204 の操作の呼び出し元は結果を読まないことを OpenAPI と照合した。
`Content-Length` のない空の本文は読めない本文として扱う。製品の API は Go の `net/http` が `Content-Length: 0` を付けるため、この区別に入らない。
