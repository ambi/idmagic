# パスカルケースの列挙値を小文字のスネークケースに統一する

九つの独自列挙を小文字のスネークケースへ統一し、TypeSpec、Go の定数、PostgreSQL の制約とデフォルト値、検索 SQL、管理画面とテストを揃えた。
REQ-SYSTEM-035 を追加し、サインインの強度と鍵用途を述べる既存要件も新しい表記へ追従させた。
SharedSignals の署名済み SET に送る `reason` は従来のパスカルケースを保ち、全十五理由の送信境界を検証する。
保持すべき既存データがないという利用者の指示に従い、データ移行と旧値の互換読み取りは追加せず、未公開の OpenAPI ベースラインも更新していない。
再発した鍵無効化の UI 試験は、通信の完了と React の更新を明示的に待ち、成功通知の実時間のポーリングを除いた。
通信の代役もブランド取得、無効化、利用不能な一覧取得に分け、応答の前後で行と通知を観測する。
