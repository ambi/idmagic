# 日常開発の規則の重複を減らし、変更に必要な規則と背景説明を分ける

`mise run spec-diff -- c097fabce` は規範仕様の変更なしを報告した。
開発規約の重複を所有文書への参照へ替え、背景、出典、初期の導入理由を既存のフォーマットの理由へ移した。
実装スキルと入口を同期し、代表作業の共通規則の文字数を約 19〜27% 減らした。参照ファイル数は変わらず、開く節は 2〜4 件増えた。
利用者の追加指示に従い、一律の全体検査と先行 Go lint を要求する規約を修正した。実際の差分と影響から最小の検査を選び、不明な範囲を広げ、Go の race 検査の必要性を別に判断する。
製品の要件、RED と変更耐性の適用条件、CI の必須検査は維持した。
