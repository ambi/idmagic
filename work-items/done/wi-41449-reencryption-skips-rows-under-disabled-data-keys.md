# 無効化したバージョンの行が再暗号化を止めないようにする

REQ-DATAKEYS-010 を追加し、無効化済みと破棄済みの鍵の行を残して、ほかのバージョンの再暗号化を進めるようにした。
全 4 種類の `FieldMigrator` がバッチ上限の適用前に対象のバージョンを除外するため、無効な行が先頭を占めても退役した鍵の行を移せる。
除外した行は未移行件数に残し、復号の拒否と、参照が残る間の破棄の拒否を維持する。
移行が 0 件の実行は続きのジョブを投入せず、定期実行か手動の掃引で再確認する。
鍵の状態の取得や移行対象の暗号処理の失敗は引き続きジョブを失敗させる。
破棄を起動する経路と、読めなくなった値の再入力や削除の操作は対象外とした。
