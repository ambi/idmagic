# WS-Trust の再送防止を OAuth2 のクライアント認証ポートから分ける

WS-Trust の再送防止を WsFederation が所有する `MessageIDReplayStore` へ移し、OAuth2 への本番 import を取り除いた。
要求側の最小のポートを既存のストアが構造的に満たすため、JOSE の契約の共有や委譲だけのアダプターは追加しなかった。
組み立て地点が渡す保存先、`wstrust:` のキー、5 分の有効期間、記録の順序、拒否とイベントを維持し、`spec-diff` に規範仕様の差分はなかった。
テストを変更せず、逆依存を含む 870 件の race 検査と、lint、境界、負債の増加、仕様、リンクの検査を通し、設計と依存図を更新した。
配線を切る故障と条件反転を既存テストが検出し、生存変異はなかった。
未配線時に処理を続ける現状の是正、保存スキーマとアルゴリズム、RP の管理は対象外とした。
