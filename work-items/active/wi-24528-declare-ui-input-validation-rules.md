# UI の入力検証を API プロパティの制約と直接照合する

## 動機

[検証の分担](../../docs/design/application/user-interface.md#検証の分担)は、入力だけで判定できる検証を SPA が担い、受理範囲を欄ごとにサーバーの検証とそろえ、上限と範囲を TypeSpec の `@maxLength`、`@minValue`、`@maxValue` から取ると定める。
2026-11-22 時点で `frontend/src/` のテスト以外の 35 ファイルが `formSchema(...)` を 38 回呼び、欄の規則を `frontend/src/lib/form.ts` の部品で組み立てている。
上限は `frontend/src/lib/lengthLimits.ts` の `LENGTH` に手で写しており、欄の規則と送信先の API プロパティの制約を照合する検査はない。

UI ページ設計は入力項目を宣言しない。
`formSchema` のキーと送信処理から API プロパティとの対応を取り、既存の規則を直接比べれば、ページごとの入力項目の写しを保守せずに不一致を検出できる。

## 対象範囲

- 実装の `formSchema` の欄と検証部品を抽出し、送信先の API プロパティの TypeSpec 制約と直接照合する。
- API では任意だが画面では必須、確認用の値の一致、複数プロパティへの分解など、UI 固有の規則と変換だけを理由付きの例外として記録する。
- `LENGTH` の値と TypeSpec 制約の不一致を検出する。
- 照合できない欄と API との不一致を列挙して分類し、検査で既知の差と新たな差を区別する。

## 対象外

- 不一致の修正。受理範囲など製品の振る舞いを変えるものは、個別の bugfix 項目として起票する。
- API 契約、backend の検証、ページ設計のモデルの変更。
- 全フォーム部品への `name` 付与、ページ・フォーム・入力項目の識別子の宣言。
- エラー文、表示位置、`aria` 属性の規則。[検証の分担](../../docs/design/application/user-interface.md#検証の分担)が定める。

## 設計

### API の制約と UI の例外

長さ、数値範囲、列挙、形式の期待値は API プロパティの型と decorator から導き、別の宣言へ写さない。
実装の `formSchema({ key: rule(...) })` のキー、送信先の操作、送信時の変換から対応を確認する。
同名のキーだけで API のモデルを推測せず、曖昧な箇所に限って操作とプロパティへの参照を補う。
API と異なる必須性、確認用の値、項目間の条件には、画面の目的または既存仕様を根拠とする例外を置く。
パスワードとシークレットに上限を課さない既存規則も照合する。

### 着手時に決めること

ユーザーの作成と編集、ログイン、アプリケーションの作成を代表に、実装から得られる対応と最小の明示的な参照の置き場所を比べる。
欄の一覧や受理範囲を手で複製する案は採らない。
`formSchema` を使わない確認コードや独自検査は所在と理由を列挙し、黙って照合済みと扱わない。
既知の不一致には根拠と修正を担当する作業項目を要求し、新たな不一致を通常の検査で拒否する。
ページ設計への依存は必要ないため、wi-92664 の完了を前提にしない。

## 計画

1. 代表例で送信先と欄の対応を確認し、抽出と例外の形式を確定する。
2. API 制約の導出と `formSchema` の抽出を実装し、部品の種類と値を照合する。
3. 全 `formSchema` の不一致と照合できない箇所を分類し、修正が必要なものを別項目へ分ける。
4. 照合を通常の検査へ接続する。

## 検証

- `mise run test-tools-file -- <対象テスト>`：API の対応違い、上限と検証部品の不一致、理由のない例外を検出する。
- `mise run check-work-items` と `mise run check-links`：例外の根拠と修正項目への参照を検査する。
- `mise run verify-changed -- <base>`：差分に応じた型検査、lint とテストを実行する。

## リスク

- 同名のキーが別の API モデルを指す。送信先を特定し、推測できない対応は明示する。
- 例外が受理範囲の写しになる。既存の API 制約は導出し、API と異なる判断だけを記録する。
- 多数の不一致の修正が混ざる。今回の範囲は検出と分類までに限る。
