# AI エージェントのデモを設定済みで始められるようにし、残る入力の意味と出所を示す

## 動機

現在のデモは、統制の効果を見るまでに六つ前後の手順で管理画面とデモ画面を往復し、ID とシークレットを控えて貼る必要がある。
「確かめる制御の範囲」で通常と文書ごとの二つの手順を選ばせ、切り替えると手順を最初から読み直す。
何を入力しているのか、その値がどこから来てどこで使われるのかも、手順の文章を読まなければ分からない。
そのため、統制の効果を見せたい場面でも設定作業が主役になり、Okta や Ping より複雑に見える。

設定の簡単さを示すことと、統制の効果を示すことは別の目的である。
前者は製品の改善（[wi-95247](../done/wi-95247-discover-mcp-tools-and-automate-connection-setup.md)、[wi-85817](wi-85817-register-agent-credentials-and-connections-in-one-flow.md)、[wi-24427](wi-24427-restrict-tools-to-targets-without-authoring-a-model.md)）で減らし、デモは両方を分けて見せる。

## 対象範囲

- 起動時に「設定済みで始める」と「自分で設定する」を選べるようにする。
- 「設定済みで始める」は、管理者として明示的に許可した後、デモが管理画面と同じ管理 API で接続先、Agent、認証、割当を作る。製品に裏口を作らない。
- 設定済みの場合は「準備した設定」の一覧を表示する。各行に、作ったもの、値、値の出所（自動取得、生成、選択、固定値）、なぜ必要か、管理画面で開くリンクを示す。
- 「自分で設定する」は、各入力欄に出所の印（あなたが決める、デモが渡す、前の手順の結果、既定値）と、その値がどこで使われるかを一文で示す。
- 通常と文書ごとの二択をやめ、通常の管理を設定した後に「文書ごとに絞る」を追加の一手順として示す。
- デモと管理画面の値の受け渡しを、明示的に対応付けた localhost のデモに限って自動化し、ID、シークレット、公開鍵の再入力をなくす。
- 「自分で設定する」の手順数、手入力の数、転記の数をデモ画面と手引きに示し、E2E でその数を固定する。
- Okta と Ping の公式手順から同じ課題の必須操作を数え、手引きの比較表へ記載する。数えた日と根拠の手順を残し、実機の計測とは区別する。

## 対象外

- 製品の管理画面の再設計。各作業項目で扱う。
- 競合製品の実テナントでの操作と計測。
- 削除一回への承認の拘束と、承認のために区分を「監督下」へ変える手順の解消。[承認した操作の扱い](wi-83492-decide-approved-operations-through-the-mcp-gateway.md)の判断に従う。

## 設計

### 設定済みの開始点

| 案 | 利点 | 制約 |
| --- | --- | --- |
| 管理者のログインと明示的な許可の後、デモが管理 API を呼ぶ | 製品の振る舞いと監査イベントをそのまま見せられる。設定内容を管理画面で確かめられる | デモに管理者の権限を一時的に渡す方法を決める必要がある |
| `mise run demo-agent` の起動時にシードで作る | 実装が単純 | 誰の操作で作られたかが監査に残らず、製品の手順を飛ばしたように見える |
| 手順の値を自動入力するだけ | 製品の変更が要らない | 画面往復と保存操作は残り、効果を見せる目的に対して遅い |

一案目を推薦する。
管理 API の呼び出しに必要な権限の受け渡しは、既存の認証方式から選び、デモ専用の製品機能を追加しない。
既存の方式で成立しない場合は二案目に切り替え、作成者を「デモの起動処理」として手引きに明記する。

### 入力の出所と設定量

出所の語は [wi-85817](wi-85817-register-agent-credentials-and-connections-in-one-flow.md) と同じ四つに揃える。
手順数、手入力、転記は E2E が操作した入力欄から数え、手作業の数え直しに頼らない。
比較表では、初期構築と日常の付与を分け、IdMagic 側の事前準備を省かない。
製品の改善が入るたびに数を更新し、改善前より増えた場合は E2E を失敗させる。

## リスク

設定済みの開始点だけを見せると、製品の設定が簡単だという誤解を招く。
「準備した設定」の一覧に同じ設定を手で行う場合の手順数を併記し、手引きの比較表は「自分で設定する」の数で示す。
デモに管理者の権限を渡す経路が、localhost 以外の任意のサイトから使えると危険である。
デモのオリジンと起動したプロセスに限定し、権限は作成の完了後に破棄する。
