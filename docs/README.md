# IdMagic ドキュメント

IdMagic は、人間とエージェントのアイデンティティ、認証、委譲、プロビジョニングをテナント単位で管理するアイデンティティ基盤である。

| 区分 | 内容 |
| --- | --- |
| [要件文書](requirements/README.md) | プロダクト概要、機能要件、品質要件、外部規範への準拠、システム横断シナリオ、用語集 |
| [全体設計文書](design/README.md) | アーキテクチャ設計と、アプリケーション、データ、インフラストラクチャ、セキュリティ、信頼性、性能、オブザーバビリティ、検証の各設計 |
| [モジュール設計文書](modules/README.md) | モジュールごとの責務、公開契約、機能仕様、内部設計 |
| [開発文書](development/README.md) | 開発環境、テスト、CI、リリース、仕様先行の進め方 |
| [運用文書](operations/README.md) | サービス管理、保守、運用手順 |
| [リファレンス](../spec/main.tsp) | TypeSpec から生成した API リファレンスとモデルカタログ。生成サイトではリファレンスの索引を開く |
| [フォーマット](formats/README.md) | 文書の配置、仕様と設計と作業項目の記述規約 |
