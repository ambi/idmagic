# IdMagic ドキュメント

IdMagic は、人間とエージェントのアイデンティティ、認証、委譲、プロビジョニングをテナント単位で管理するアイデンティティ基盤である。
製品の目的と範囲は[プロダクト概要](requirements/product-overview.md)に示す。

| 区分 | 内容 | 入口 |
| --- | --- | --- |
| 要求文書 | プロダクト概要、機能要求、品質要求 | [要求文書](requirements/README.md) |
| 設計文書 | アーキテクチャ、領域別の設計、検証設計 | [設計文書](design/README.md) |
| ドメイン設計文書 | 用語、標準仕様、横断シナリオ、Bounded Context ごとの責務と内部設計 | [ドメイン設計文書](domain/README.md) |
| 開発文書 | 開発環境、テスト、CI、リリース、仕様先行の進め方 | [開発文書](development/README.md) |
| 運用文書 | サービス管理、保守、運用手順 | [運用文書](operations/README.md) |
| リファレンス | TypeSpec と規範シナリオから生成した API、モデル、トレーサビリティ | 生成サイトの「リファレンス」 |
| フォーマット | 文書、仕様、作業項目の記述規約 | [文書ガイド](../DOCUMENTATION_GUIDE.md)、[仕様フォーマット](../SPECIFICATION_FORMAT.md)、[作業項目フォーマット](../WORK_ITEM_FORMAT.md) |
