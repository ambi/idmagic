# 要件文書

この文書は、IdMagic の目的、対象範囲、満たすべき機能と品質、準拠する外部規範を記載する要件文書の入口である。
要件文書は ISO/IEC/IEEE 29148 のシステム要件にあたり、設計の入力になる。
要件をどう実現するかは[全体設計文書](../design/README.md)と[モジュール設計文書](../modules/README.md)に記載する。

| 文書 | 内容 |
| --- | --- |
| [プロダクト概要](product-overview.md) | 解決する課題、利用者、対象としない責務 |
| [機能要件](functional.md) | 機能群と、それを実現するモジュールへの割り当て |
| [品質要件](quality.md) | 品質特性ごとの要件、品質目標、測定境界、キャパシティ受入れ目標、復旧目標 |
| [全体の標準仕様](standards.md) | システム全体として準拠する外部規範 |
| [システム横断シナリオ](scenarios.feature.md) | 一つのモジュールでは起こせない振る舞いの規範シナリオ |
| [用語集](glossary.md) | モジュールを跨いで意味が固定される語 |
