# DataKeys のセキュリティ

この文書は、DataKeys が項目の暗号化と復号で守る性質を扱う。
鍵の種類ごとの生成、保存、失効、廃棄、復旧は[秘密情報の設計](../../../design/security/secrets.md)が扱う。

## 追加認証データによる束縛

項目の暗号化は、追加認証データ（AAD）に `(tenant, context, table, record id, field)` を含める。
暗号文を別のテナント、テーブル、レコード、項目へ複製しても、AAD が一致しないので復号できない。
DEK のバージョンは AAD に含めず、項目を持つ Context が暗号文とともに保存したバージョンで DEK を選ぶ。

## 復号の失敗時の拒否

次のどの場合も、復号を `DataKeyUnavailableError` で拒否する。

- アンラップに失敗した、またはマスターキーのプロバイダーへ到達できない。
- マスターキーの ID が、要求したテナントのものと一致しない。
- 保存したバージョンが `disabled` または `destroyed` である。
- 追加認証データが一致しない、または改ざんを検知した。

`FieldCipher` には、平文へ退避したり、その項目だけを読み飛ばして残りを返したりする経路はない。
