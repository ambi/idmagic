# 信頼済みデバイス

第二要素の成立後に本人が記憶させたブラウザーの発行、有効期間、効果の範囲、失効を扱う。
第二要素を求めるかの判定そのものは多要素認証が扱う。
コードの機能スライスは `backend/authentication/trusteddevice` である。
