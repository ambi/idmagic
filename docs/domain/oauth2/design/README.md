# OAuth2 の設計

この文書は、OAuth2 の設計を話題ごとに索引する。
このモジュールが外へ約束することは、仕様の [OAuth2](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。

| 話題 | 記述した場所 |
| --- | --- |
| アーキテクチャ | [OAuth2 のアーキテクチャ](architecture.md) |
| 設計判断 | [OAuth2 の重要な設計判断](decisions.md) |
| アプリケーション | 該当なし：プロトコルの形は[標準仕様](../standards.md)と TypeSpec が、管理 API はシステムの[アプリケーション設計](../../../design/application/README.md)が扱う |
| データ | 該当なし：トークンの有効期間と保持期間は[トークンの設計](../token/design.md)が、テーブルの定義はスキーマファイルが扱う |
| セキュリティ | 該当なし：各機能の設計のセキュリティの節と、システムの[認可設計](../../../design/security/authorization.md)が扱う |
| 信頼性 | 該当なし：署名の提供元の障害は[トークン](../token/README.md)が、ログアウトの配信の再試行は[ログアウトの設計](../logout/design.md)が扱う |
| 性能 | 該当なし：システムの[性能設計](../../../design/performance/README.md)に従い、このモジュールに割り当てた品質要件はない |
| オブザーバビリティ | 該当なし：システムの[オブザーバビリティ設計](../../../design/observability/README.md)に従い、このモジュールに固有の信号はない |
| 検証 | [OAuth2 の検証](verification.md) |
| インフラストラクチャ | 該当なし：実行基盤に固有の要求はない |
| リスク | 該当なし：このモジュールに固有の既知の欠陥は見つかっていない |
