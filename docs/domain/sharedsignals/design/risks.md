# SharedSignals のリスク

この文書は、SharedSignals の既知の欠陥、技術的負債、受容したリスクを扱う。
脅威は[脅威モデル](../../../design/security/threat-model.md)に置く。

| リスク | 現状 | 影響 |
| --- | --- | --- |
| `worker` が発行したイベントでは失効エポックが進まない | Agent と所有者のイベントに反応して失効エポックを進める仕組みは、`api` のプロセスの配信点にだけ組み込まれている | `worker` で実行する操作（ライフサイクルワークフローによる User の無効化など）が発行したイベントでは、配下の Agent の失効エポックが進まず、外部への伝播も起きない |
| 配信不能の配送をやり直す手段がない | `dead_letter` に達した配送を、`pending` へ戻す操作も、作り直す操作もない | 受信側の長い障害の後、その間の失効は外部へ伝わらないまま残る |
