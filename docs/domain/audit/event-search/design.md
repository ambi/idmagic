# 監査イベントの検索の設計

この文書は、[監査イベントの検索](README.md)の要件を保証する仕組みを扱う。

## データ

検索属性は、イベントごとの副表に、属性の名前と値の組として保存する。
副表は、一つのイベントの一つの属性に複数の値を持てる。
委譲チェーンの参加者（`delegation.actor`）はこの多値の属性であり、チェーンに現れる主体をそれぞれ 1 行として書く。
絞り込みは属性の行に対する存在の判定なので、単値の属性にも同じ判定がそのまま適用される。

副表は、イベントのペイロードから再生成できる派生データである。
登録簿の検索属性は、現状どれも変換を持たず、平文のまま保存する。

検索軸を後から追加しても、記録済みのイベントへ遡って行を書き足さない。
理由は[検索軸を記録済みのイベントへ遡って書き足さない](../design/decisions.md#検索軸を記録済みのイベントへ遡って書き足さない)に置く。
