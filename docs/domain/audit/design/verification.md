# Audit の検証

この文書は、Audit の要件と統制のうち、例のテストのほかに確かめているものを扱う。
システム全体の検証の方式は[検証設計](../../../design/verification/README.md)に従う。

## パースの境界のファズテスト

`ParseAuditFilter` は、Go のネイティブのファジングの対象である。
オラクルは、受理した式の属性が検索属性の登録簿に存在し、演算子がその属性の許す集合に含まれることである。
フィルターはこの先でクエリの組み立てに使われるため、許可の集合を経ない属性や演算子が通ると、監査ログの検索が意図しないカラムや比較へ広がる。
