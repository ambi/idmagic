# 関係タプル

## 概要

この文書は、関係タプルを一括で書き込み、オブジェクトの削除でその関係タプルを取り除く仕様である。

| 項目 | 内容 |
| --- | --- |
| 責務 | 登録済みのモデルに適合する関係タプルの一括の追加と削除、オブジェクトの両側の関係タプルの削除 |
| 行為者 | テナント管理者 |
| 扱わないもの | 関係タプルを使う判定は[関係の判定](../check/README.md)が扱う |

## モデル

主体は `type:id`、`type:id#relation`（subject set）、`type:*`（ワイルドカード）の三つの形を取る。
ワイルドカードは、`direct` の規則がその型を許した場合にだけ受理する。
関係タプルはテナントの中で一意な組であり、同じ組の再書き込みは冪等である。
`direct` の規則が宣言していない形の関係タプルは、書き込みで拒否する。

## 操作

### 管理者による関係タプルの書き込み

#### REQ-AUTHORIZATION-002 関係タプルの書き込みは登録済みモデルに適合するものだけを一括で適用する

### 管理者によるオブジェクトの削除

#### REQ-AUTHORIZATION-008 オブジェクトの削除はその両側の関係タプルを取り除く

## セキュリティ上の考慮

関係タプルの読み書きは、常に呼び出し元のテナントで解決した `tenant_id` に閉じる。
要求の本文が別のテナントの識別子を含んでいても、それが書き込みの対象のテナントを変えることはない。
