# テナント設定

テナント管理者が自身のテナントに設定する表示名、セキュリティポリシーの上書き、通知のデフォルト言語を扱う。
上書きされた値を使う判定そのものは扱わない。パスワードの検証と信頼済みデバイスは `Authentication` が、委譲の深さの判定は `OAuth2` が扱う。
