# テナント設定の設計

この文書は、[テナント設定](README.md)の要件を保証する仕組みを扱う。

## アーキテクチャ

上書きを使うモジュールは、`TenantRepository` を直接参照しない。

| 使う側 | 依存する境界 | 実装 |
| --- | --- | --- |
| `OAuth2` の Token Exchange | 委譲の深さを返す小さなポート | `oauth2/policy_tenancy` のアダプターが、ポートを `Tenant` の実効値へ接続する |

## 信頼性

上書きを読めないとき、Token Exchange はシステムデフォルトへ退避せずに拒否する。
退避すると、テナントが意図して下げた委譲の深さを黙って広げるからである。
