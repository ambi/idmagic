# SigningKeys のリスク

この文書は、SigningKeys の既知の欠陥、技術的負債、受容したリスクを扱う。
脅威は[脅威モデル](../../../design/security/threat-model.md)に置く。

| リスク | 現状 | 影響 |
| --- | --- | --- |
| XML フェデレーションの鍵は自動でローテーションもアーカイブもされない | `idmagic-batch signing-key-lifecycle` は、テナントごとに `Signing` の用途のデフォルトのスコープだけを扱う | `XmlFederationSigning` の鍵は、管理者がローテーションしない限り入れ替わらない。期限の過ぎた検証用の鍵はメタデータから外れるが、`Archived` にならない |
| 検証用の鍵の無効化がドメインイベントを発行しない | 無効化は鍵をアーカイブするが、イベントを発行しない。`SigningKeyRetired` は宣言されているが、どの処理も発行しない | 鍵の無効化が監査の記録に残らない |
| 状態遷移の表が無効化を表さない | 無効化は `Verifying` の鍵を直接 `Archived` にするが、機能仕様の状態遷移の表にこの遷移はない | 状態遷移の表から、無効化の後の鍵の状態を読み取れない |
