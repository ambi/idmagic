# ポータルのアプリケーション

## 概要

この文書は、エンドユーザーがポータルで自分のアプリケーションを一覧し、並べ替える仕様である。

| 項目 | 内容 |
| --- | --- |
| 責務 | 割り当て済みのアプリケーションの一覧、手動の並び順の保存と適用 |
| 行為者 | EndUser、API トークンの発行者 |
| 扱わないもの | 割り当ての作成と解除は[割り当て](../assignment/README.md)が扱う |

## モデル

`ListMyApplications` は、割り当て済みで、表示され、有効なアプリケーションを解決してから、保存済みの並び順を適用する。
割り当てが外れた項目は除き、保存済みの並びにない割り当て済みのアプリケーションは、名前の順で末尾に加える。
並び順を保存していない場合は、すべてを名前の昇順に並べる。
そのため、割り当てが並行して変わっても、一覧は壊れない。

`ReorderMyApplications` は並び順を作成または更新するだけであり、個人の表示の設定なので、ドメインイベントを発行しない。

## 操作

### 利用者によるポータルのアプリケーションの操作

#### REQ-APPLICATION-003 API トークン発行者は account スコープで自分のポータルアプリケーションだけを操作できる

## セキュリティ上の考慮

エンドユーザーが触れるのは自分自身の範囲だけである。
`ListMyApplications` と `ReorderMyApplications` は認証済みの本人の割り当てと表示の設定に閉じ（`account:applications_read`）、ほかのユーザーの一覧や並び順へは到達できない。
