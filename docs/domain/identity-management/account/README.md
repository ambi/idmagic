# アカウントのセルフサービス

認証済みの本人が `/api/account/*` で行う操作を扱う。
アカウントの概要、プロフィールの参照と更新、メールアドレスの変更と確認、アカウントデータのエクスポートが対象である。
コードは `backend/idmanagement/user` の機能スライスにある。
パスワード、認証要素、セッションの本人操作は `Authentication` が扱う。
