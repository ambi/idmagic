# CSV の転送

## 概要

この文書は、User と Group の CSV のインポートとエクスポートが共有する、ファイルとセルの読み書きの規則の仕様である。

| 項目 | 内容 |
| --- | --- |
| 責務 | 見出しと行の読み取り、転送ポリシーの上限、セルの数式の保護、属性値のセルの字句形、成果物の保持 |
| 行為者 | 管理者（CSV のインポートとエクスポート）、Batch の保持期限の削除（`retention-sweep`） |
| 扱わないもの | User の列と行の計画は[ユーザー CSV](../user-csv/README.md)が、Group とメンバーシップの列と行の計画は[グループ CSV](../group-csv/README.md)が、エクスポートのジョブは[データエクスポート](../data-export/README.md)が扱う |

## 操作

### 見出しと行の読み取り

#### REQ-IDMANAGEMENT-034 CSV の見出しは機械キーと完全に一致する名前だけを受け付ける

- CSV を読むとき、見出しの先頭の UTF-8 の BOM を取り除いてから照合する。
- 見出しの各列名は、大文字と小文字、前後の空白を含めて、種別が受け付ける機械キーと完全に一致しなければならない。
- 機械キーと一致しない列名を含むファイルを受けた場合は、`invalid_header` で拒否する。
- `password`、`password_hash`、`mfa_secret`、`token`、`recovery_code` を見出しに含むファイルを受けた場合は、種別によらず `invalid_header` で拒否する。
- 見出しの行もない空のファイルを受けた場合は、`invalid_csv` で拒否する。
- 見出しでファイルを拒否した場合は、どの行も計画しない。

#### REQ-IDMANAGEMENT-035 列の数が見出しと異なる行は、その行だけを拒否する

- 列の数が見出しの列の数と異なる行を読んだ場合は、その行を `invalid_column_count` で `rejected` とし、続く行の解析と計画を続ける。
- 転送ポリシーの上限を超えた場合、または RFC 4180 として読めない場合は、その位置でファイル全体の解析を止める。

#### REQ-IDMANAGEMENT-037 CSV の転送ポリシーの上限は、上限と等しい値を受け付け、超えた値を拒否する

| 上限 | デフォルト値 |
| --- | --- |
| データ行の数 | 100,000 行 |
| 成果物の大きさ | 64 MiB |
| 一つの項目の大きさ | 64 KiB |

- データ行の数は、見出しの行を除いて数える。
- どの上限も、上限と等しい値は受け付ける。
- 上限を超えた値を受けた場合は、拒否する。
- 上限は一つの成果物に対するもので、テナントの User や Group の件数を制限しない。

### セルの読み書き

#### REQ-IDMANAGEMENT-036 先頭のアポストロフィーは、数式の保護として付けたものだけを取り除く

- インポートがアポストロフィーで始まり、その次の文字がアポストロフィーまたは `=`、`+`、`-`、`@`、タブ、CR、LF のセルを読んだとき、先頭の一文字を取り除く。
- インポートがそれ以外のアポストロフィーで始まるセルを読んだとき、そのまま読む。

#### REQ-IDMANAGEMENT-038 属性値のセルは型ごとの正規の字句形だけを受け付ける

| 型 | 受け付ける字句形 |
| --- | --- |
| `string` | 任意の文字列 |
| `date` | `YYYY-MM-DD` の暦日 |
| `number` | 最短の十進表記。`1.0` や `01` は受け付けない |
| `boolean` | `true` または `false` |
| `string_array` | 空白を含まない JSON の文字列配列 |

- エクスポートは、同じ字句形で値を書き出す。
- User の CSV と Group の CSV は、同じ字句形を使う。
- 任意の属性の空のセルを読んだとき、その属性を消す。
- 型の字句形に合わないセルを読んだ場合は、拒否する。
- 必須の属性の空のセルを読んだ場合は、拒否する。

### 成果物の保持

#### REQ-IDMANAGEMENT-080 CSV の成果物は、作成から 30 日を過ぎると消す

- 保持期限の削除を実行したとき、作成の時刻が実行の時刻の 30 日前より前の CSV の成果物を、分割したペイロードごと消す。対象は、エクスポートのファイル、インポートのペイロード、行のエラーのページである。
- 保持期限の削除は、作成の時刻が実行の時刻の 30 日前ちょうどか、それより後の成果物を消さない。
- **判断**：エクスポートの成果物は完了の時点で作るので、作成から 30 日で消すと、エクスポートの保持期限（REQ-IDMANAGEMENT-079）と同じ時点で消える。インポートのペイロードは、プレビューのジョブの記録と同じ期間だけ残る。
- **例**：EX-IDMANAGEMENT-080-01
