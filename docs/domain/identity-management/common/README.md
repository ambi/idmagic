# 共通

User、Group、Agent のどの種類のプリンシパルにも共通してかかる規則を扱う。
管理 API の呼び出しを認める条件と、ロールを書き込むときの正規化と予約ロールの制限である。
どれも、特定の Aggregate の操作ではなく、すべての管理操作の入口で同じ判定を通す。
システム全体の認可の規則（主体の種類、スコープの名前空間、テナント境界）は[認可設計](../../../design/security/authorization.md)が扱う。

| 文書 | 内容 |
| --- | --- |
| [管理 API の認可](admin-access/README.md) | 管理者のセッションと API アクセストークンによる管理 API の呼び出しを認める条件 |
| [ロール](roles/README.md) | ロールの正規化と、予約ロール `system_admin` を割り当てられる対象 |
