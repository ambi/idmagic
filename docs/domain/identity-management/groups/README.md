# グループ

User を束ねてロールをまとめて付与する `Group` と、その所属の決め方を扱う。
所属は、管理者が決める手動の所属と、CEL の規則の評価が決める動的な所属の二通りである。
CSV による Group とメンバーシップの一括の変更は[一括転送](../bulk-transfer/README.md)が扱う。

| 文書 | 内容 |
| --- | --- |
| [グループ](group/README.md) | `Group` の作成と更新、連絡先とカスタム属性、手動のメンバーシップ、実効ロール |
| [動的グループ](dynamic-group/README.md) | CEL の規則の保存、プレビュー、全件の再評価による所属 |
