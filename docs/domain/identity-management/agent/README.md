# エージェント

非人間のプリンシパル `Agent` の登録、所有者、`OAuth2Client` への資格情報のバインド、無効化と再有効化、キルスイッチ、削除を扱う。
コードの機能スライスは `backend/idmanagement/agent` である。
エージェントがトークン交換の actor として振る舞う委譲の仕組みは `OAuth2` が扱う。
