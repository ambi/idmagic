# 起動時設定

## 概要

この文書は、プロセスの起動時設定の検証と、設定の参照文書の生成と、実行時に選べる機能のレジストリの仕様である。

| 項目 | 内容 |
| --- | --- |
| 責務 | 起動時設定の集約した検証、検証に失敗したときの停止、`ConfigurationReference` の生成と乖離の検出、`FeatureRegistry` の検証と解決 |
| 行為者 | Operator |
| 扱わないもの | 個々の設定の意味は、その設定を読む各モジュールが扱う |

## モデル

実行時に選べる機能は、起動処理が静的に組み立てる `FeatureRegistry` を唯一の一覧とする。
レジストリでは API の安定性、標準の採否、テナントの設定を管理せず、実行時の選択と更新の影響だけを記録する。
常に提供する機能は登録せず、選べる機能のないビルドでは、空のレジストリを有効な状態として扱う。

| 語彙 | 値 |
| --- | --- |
| 成熟度 | `experimental`、`preview`、`supported`、`deprecated` |
| 更新の方針 | `rolling`、`recreate_on_version_change`、`recreate_always` |

実験的な機能はデフォルトで無効とし、非推奨の機能を新たにデフォルトで有効へ変えることは、レジストリの検証で拒否する。

## 操作

### 運用者によるプロセスの起動

#### REQ-SYSTEM-016 起動時設定の検証に失敗するとプロセスは部分起動せず集約エラーで停止する

- 運用者がバックエンドのプロセス（`idmagic`、`idmagic-worker`、`idmagic-batch`、`idmagic-seed`）を起動したとき、System は、環境変数から設定を集めて検証し、すべての検証のエラーを 1 回の起動の試行で集約して報告する。
- 検証のエラーと起動のログを書くとき、System は、シークレットに分類した値（DSN、SMTP の資格情報、API キー）を含めない。
- すべての検証を通ったとき、System は、明示の指定、デフォルト値、依存の閉包から有効な機能を決め、検証済みの設定で初期化を終える。
- 明示的に有効にした `experimental` か `preview` の機能か、有効な `deprecated` の機能があるとき、System は、識別子と成熟度だけをシークレットを含まない起動の警告に記録する。
- 必須の値がないか、値の型か範囲が不正か、組み合わせが矛盾する（`persistence=postgres` で DSN が空）場合、System は、該当するキーか組み合わせを含む集約エラーで終了し、リスナーの待ち受け、永続化の依存先への接続、seed の適用を始めない。
- `FeatureRegistry` に識別子か版の名前の重複、存在しない依存、依存の循環、実験的な機能のデフォルトの有効化、非推奨の機能の新たなデフォルトの有効化がある場合、System は、すべてのレジストリのエラーを返して起動を止める。
- `FEATURES_ENABLE` か `FEATURES_DISABLE` が存在しない機能を指すか、同じ機能を両方で指定するか、明示的に無効にした依存を要する場合、System は、すべての選択のエラーを返して起動を止める。
- **例**：EX-SYSTEM-016-01、EX-SYSTEM-016-02、EX-SYSTEM-016-03、EX-SYSTEM-016-04、EX-SYSTEM-016-05、EX-SYSTEM-016-06

### 運用者による設定の参照文書の生成

#### REQ-SYSTEM-017 ConfigurationReference は起動時設定の定義から生成され乖離を検出できる

- 運用者が設定の参照文書を生成したとき、System は、設定できる各キーのキー名、値の型、デフォルト値、必須かどうか、読むプロセス、説明と、`FeatureRegistry` の各機能の識別子、版、成熟度、デフォルトの有効化、依存、更新の方針を書き出す。
- 設定の参照文書を生成するとき、System は、シークレットに分類したキーの値を書かず、シークレットであることだけを示す。
- `FeatureRegistry` が空のとき、System は、選べる機能がないことを参照文書に示す。
- 運用者が機能のメタデータを要求したとき、System は、メタデータの形式の版と、有効な各機能の識別子、版、成熟度、更新の方針を返し、シークレットと無効な機能を返さない。
- 生成物が定義と一致しない場合、System は、突き合わせを失敗させ、乖離したキーを報告する。
- **例**：EX-SYSTEM-017-01、EX-SYSTEM-017-02
