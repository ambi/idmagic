# 文章の言語

この文書は、リポジトリ内の文章をどの言語で書くかを定める。

リポジトリ内の人が読む文章は日本語で記述する。Markdown はタイトル、見出し、表見出し、リンクラベルを含めて日本語とし、同じ内容の英語の文書を併記しない。ソースコード、TypeSpec、設定、テストに含まれるコメントと説明文も日本語にする。

英語で記述する文章は、API エラーメッセージ、ログメッセージ、CLI ヘルプ、コミットメッセージ、`en` ロケールの利用者向け UI 文言だけとする。`ja` ロケールの利用者向け UI 文言は日本語にする。

識別子、リテラル値、ファイルパス、コマンド、製品名、プロトコル名、規格名、頭字語、外部契約で定められた名前は文章の言語とは区別し、意味を保つため必要な原表記を使う。Go と TypeScript の識別子、データベース列、イベント名、エラーコード、スコープ、`REQ-<MODULE>-NNN`、TypeSpec のシンボル、frontmatter のキーはこの扱いに含む。

生成する文書サイトでは、`mise run render-docs` と `mise run check-rendered-docs` が本文に残った英文を検出して失敗する。機能語を含む規格名、文書名、製品名のように原表記を保つ語句は、許容する理由の分類とともに `tools/render-docs/src/prose-language.ts` の許容語の表に載せる。
