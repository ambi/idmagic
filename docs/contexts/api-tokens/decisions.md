# ApiTokens Decisions

- API アクセストークンの発行、一覧、失効は `admin` または `system_admin` ロールを持つ、有効かつ認証済みのユーザーだけが行える。発行できるトークンは所属テナントのものに限り、`sub` は発行した本人に固定する。発行、一覧、失効そのものは API アクセストークンからは呼び出せない対話セッション限定の操作である。トークンでトークンを発行できると、任意のスコープ集合への昇格経路になるためである。
- トークンを提示した呼び出しは、発行者本人として認証される。認可には、発行者が対象操作に必要なロールを現在も持つことと、トークンのスコープ集合が対象 API を許可することの両方が必要である。発行者が後からロールを失えば、トークン自体が有効でも管理操作は通らない。スコープ集合が空のトークンはどの API も呼び出せない。
- この Context を `Generic` に分類する。テナント単位のアクセストークンを発行し、失効させ、スコープで絞る形は解決済みの問題であり、他の製品と変わらない。ここに設計を投資しない。
