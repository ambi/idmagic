# アーキテクチャ

システム要求を構成要素へ割り当て、外部境界、論理構造、実行時の相互作用、配備先の対応を別のビューで表す。
各ビューは同じ要素を別の目的で参照し、別々の正本として再定義しない。

| 文書 | 関心事 |
| --- | --- |
| [システムコンテキスト](system-context.md) | 利用者、外部システム、運用者、責任分界 |
| [論理アーキテクチャ](logical.md) | Bounded Context、共有機構、データ所有 |
| [実行時アーキテクチャ](runtime.md) | 実行単位、主要な相互作用、同期と非同期の境界 |
| [配備アーキテクチャ](deployment.md) | 実行単位の配置先、環境別構成、外部接続 |
| [アーキテクチャ上の判断](decisions.md) | 複数のビューに作用する現在有効な判断 |

ISO/IEC/IEEE 42010:2022 の関心事、視点、ビュー、対応関係を用語の基礎にする。
この配置と記法は IdMagic の選択であり、同規格がファイル構成を規定していることを意味しない。
