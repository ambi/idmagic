# Authorization の設計

この文書は、Authorization の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Authorization](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 委譲 | [関係の判定の設計](../check/design.md#データ) | 書き込みの版と永続化は関係の判定の設計が、テーブルの定義はスキーマファイルが扱う |
| 信頼性設計 | 委譲 | [関係の判定の設計](../check/design.md#アーキテクチャ) | ストアの障害は判定不能として不許可にし、関係の判定の設計が扱う |
| 性能設計 | 委譲 | [判断](decisions.md#リソースの列挙を上限付きの走査と-1-件ずつの判定で行う) | システムの性能設計に従い、列挙の規模の限界は判断に置く |
| 検証設計 | 固有設計 | [担当文書](verification.md#パースの境界のファズテスト) | パースの境界のファズテスト |
