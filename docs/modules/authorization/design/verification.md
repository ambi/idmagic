# Authorization の検証

この文書は、Authorization の要件と統制のうち、例のテストのほかに確かめているものを扱う。
システム全体の検証の方式は[検証設計](../../../design/verification/README.md)に従う。

## パースの境界のファズテスト

整合トークンの復号は、Go のネイティブのファジングの対象である。

| 性質 | 成り立つ範囲 |
| --- | --- |
| テナントをまたいだ復号を必ず拒否する | テナント ID の形によらない |
| 同じテナントでの往復 | `tenancy` が受け入れる形のテナント ID に限る。符号化がテナント ID と版を `:` で連結するので、往復はテナント ID が `:` を含まないという制約に依る |

受理するのは正規形だけである。
base64 の復号は入力の中の改行を読み飛ばし、末尾の余剰ビットもデフォルトでは無視し、版の側も先行ゼロを許すので、復号できることを条件にすると、同じテナントと版を表す文字列が無数に通る。
判定は、符号化し直したものと入力の一致で行い、この三種の余地をまとめて閉じる。
