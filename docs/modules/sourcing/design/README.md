# Sourcing の設計

この文書は、Sourcing の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Sourcing](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の機能仕様の「実現方式」の節に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 委譲 | [標準仕様](../standards.md#system-for-cross-domain-identity-management-core-schema) | SCIM のエンドポイントの形は標準仕様と TypeSpec が定める |
| データ設計 | 委譲 | [モデル](../README.md#モデル) | 対応の記録は仕様のモデルが、テーブルの定義はスキーマファイルが扱う |
| セキュリティ設計 | 委譲 | [SCIM による取り込み](../scim/README.md#セキュリティ上の考慮) | トークンによるテナントの束縛はSCIM による取り込みのセキュリティ上の考慮の節が扱う |
| 信頼性設計 | 委譲 | [SCIM による取り込みの設計](../scim/README.md#信頼性) | 作成の失敗の後始末はSCIM による取り込みの設計が扱う |
| 検証設計 | 固有設計 | [担当文書](verification.md#パースの境界のファズテスト) | パースの境界のファズテスト |
