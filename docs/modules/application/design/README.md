# Application の設計

この文書は、Application の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Application](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 固有設計 | [担当文書](data.md#application-とプロトコル設定の関係) | Application とプロトコル設定の関係、作成の原子性 |
| セキュリティ設計 | 委譲 | [割り当て](../assignment/README.md#セキュリティ上の考慮)、[サインインポリシー](../sign-in-policy/README.md#セキュリティ上の考慮) | フェデレーションの関門は割り当てとサインインポリシーのセキュリティ上の考慮の節が扱う |
