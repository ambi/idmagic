# Seeding の設計

この文書は、Seeding の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Seeding](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。

| 設計領域 | 内容 |
| --- | --- |
| [アーキテクチャ設計](architecture.md) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 該当なし：このモジュールは HTTP の操作と UI を持たず、入口はコマンドだけである |
| データ設計 | 該当なし：このモジュールは永続化を持たない。投入したデータは記録の正を持つ各モジュールが保存する |
| インフラストラクチャ設計 | 該当なし：コマンドの配置はシステムの[配置の設計](../../../design/architecture/deployment.md)が扱う |
| セキュリティ設計 | 該当なし：環境ポリシーとシークレットの扱いは[seed の計画と適用](../seed-run/README.md)のセキュリティ上の考慮の節が扱う |
| 信頼性設計 | 該当なし：部分的な失敗からの回復は[seed の計画と適用の設計](../seed-run/design.md)が扱う |
| 性能設計 | 該当なし：システムの[性能設計](../../../design/performance/README.md)に従い、このモジュールに割り当てた品質要件はない |
| オブザーバビリティ設計 | 該当なし：システムの[オブザーバビリティ設計](../../../design/observability/README.md)に従い、このモジュールに固有の信号はない |
| 検証設計 | 該当なし：システムの[検証設計](../../../design/verification/README.md)に従う |
