# Seeding の設計

この文書は、Seeding の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Seeding](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の機能仕様の「実現方式」の節に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 対象外 | — | このモジュールは HTTP の操作と UI を持たず、入口はコマンドだけである |
| データ設計 | 対象外 | — | このモジュールは永続状態を保存しない。投入したデータは記録の正を持つ各モジュールが保存する |
| インフラストラクチャ設計 | 委譲 | [配置の設計](../../../design/architecture/deployment.md#共通トポロジー) | コマンドの配置はシステムの配置の設計が扱う |
| セキュリティ設計 | 委譲 | [seed の計画と適用](../seed-run/README.md#セキュリティ上の考慮) | 環境ポリシーとシークレットの扱いはseed の計画と適用のセキュリティ上の考慮の節が扱う |
| 信頼性設計 | 委譲 | [seed の計画と適用の設計](../seed-run/README.md#信頼性) | 部分的な失敗からの回復はseed の計画と適用の設計が扱う |
