# 通知テンプレートの設計

この文書は、[通知テンプレート](README.md)の要件を保証する仕組みを扱う。

## アーキテクチャ

| 責務 | 置き場所 |
| --- | --- |
| テンプレートキーごとの差し込み変数の許可リスト | `backend/shared/notification/template` で定義し、API から返す |
| 件名、平文本文、HTML 本文の描画 | 描画処理が常に一つの単位として返す |
| 特殊文字の処理 | テンプレートではなく描画処理が受け持ち、HTML に差し込む値だけをエスケープする |
| 導線の URL | 呼び出すユースケースが要求の `issuer` から組み立て、一つの差し込み値として渡す。テンプレートは URL を配置できるが、断片から組み立てられない |

`ResetNotificationTemplate` は上書きを消すだけで、常に既知の正常な組み込みの文面へ戻る。
版の履歴を持たないので、戻す先は組み込みの文面だけである。
