# 表示言語

## 概要

この文書は、ホステッドの認証画面、管理コンソール、アカウントポータルの表示言語の決め方と、API のエラーの言語の仕様である。

| 項目 | 内容 |
| --- | --- |
| 責務 | 明示した表示言語、OIDC の `ui_locales` のヒント、起動時設定のデフォルトによる表示言語の解決、未対応のロケールのフォールバック、既知のエラーコードの翻訳 |
| 行為者 | EndUser、Administrator、ResourceOwner、Operator、APIConsumer |
| 扱わないもの | 通知メールの言語はテナントの設定と通知テンプレートが扱う |

## モデル

IdMagic が対応するロケールは `ja` と `en` だけであり、フォールバックのロケールは `en` である。
起動時設定 `VITE_DEFAULT_LOCALE` は `ja` または `en` だけを受け付け、未設定または未対応の値であれば `en` を使う。
言語の切り替えの UI で明示的に選んだ表示言語はブラウザーに保存し、以後のアクセスでは保存済みの設定を優先する。
バックエンドの API のエラーは英語で返し、UI が既知のエラーコードを翻訳する。

## 操作

### 利用者による表示言語の選択

#### REQ-SYSTEM-003 明示的に選択した表示言語でホスト認証画面が描画される

- 利用者が言語の切り替えの UI で表示言語を選んだとき、System は、ログインを含むホストの認証画面をその言語の辞書で表示し、選んだ言語をブラウザーに保存する。
- 表示言語を保存している間、利用者が画面を開いたとき、System は、保存した表示言語を優先する。
- **例**：EX-SYSTEM-003-01

#### REQ-SYSTEM-010 選択した表示言語ですべての UI 画面が描画される

- 利用者が表示言語を選んだとき、System は、画面、共有のシェル、ダイアログ、空の状態、ARIA のラベル、状態のラベルをその言語の辞書で表示し、日時と数値をその言語の書式で表示する。
- 選んだ言語の辞書に翻訳のキーがない場合、System は、フォールバックのロケール `en` の同じキーを表示する。
- **例**：EX-SYSTEM-010-01、EX-SYSTEM-010-02、EX-SYSTEM-010-03

#### REQ-SYSTEM-004 未対応のロケールはデフォルトのロケールへフォールバックする

- `ja` と `en` 以外のロケールを要求された場合、System は、デフォルトのロケールの辞書で表示する。
- **例**：EX-SYSTEM-004-01

### 運用者によるデフォルトのロケールの設定

#### REQ-SYSTEM-005 起動時設定のデフォルトロケールがフォールバックに使われる

- 運用者が `VITE_DEFAULT_LOCALE` に `ja` または `en` を設定したとき、System は、表示言語を選んでいない利用者にその言語の辞書で表示する。
- `VITE_DEFAULT_LOCALE` が未設定か、`ja` と `en` 以外の値の場合、System は、フォールバックのロケール `en` の辞書で表示する。
- **例**：EX-SYSTEM-005-01、EX-SYSTEM-005-02

### リソースオーナーによる OIDC の認可の要求

#### REQ-SYSTEM-008 OIDC の `ui_locales` ヒントにより表示言語が決まる

- 表示言語を保存していない間、`ui_locales` を含む OIDC の認可要求を受けたとき、System は、`ui_locales` のうち対応する最初の言語でログイン画面を表示する。
- 表示言語を保存している間、`ui_locales` を含む OIDC の認可要求を受けたとき、System は、保存した表示言語を優先する。
- **例**：EX-SYSTEM-008-01、EX-SYSTEM-008-02

### 管理者による管理画面の表示

#### REQ-SYSTEM-009 管理者が選択した表示言語で管理画面が表示される

- 管理者が表示言語を選んで管理画面を開いたとき、System は、管理画面をその言語の辞書で表示する。
- **例**：EX-SYSTEM-009-01

### 利用者によるエラーの表示

#### REQ-SYSTEM-011 既知のバックエンドエラーコードは UI で翻訳される

- 既知のエラーコードの応答を受けたとき、System は、UI に選んだ表示言語の辞書のエラー文を表示する。
- RFC 9457 の Problem Details の `type` を受けたとき、System は、`urn:idmagic:error:` の後の部分をエラーコードとして読む。
- 未知のエラーコードか、任意の `message` か Problem Details だけの応答を受けた場合、System は、`message`、`error_description`、`detail`、`title` のうち読める文を英語のまま表示する。
- **例**：EX-SYSTEM-011-01、EX-SYSTEM-011-02、EX-SYSTEM-011-03

### API の利用者によるエラーの受け取り

#### REQ-SYSTEM-013 バックエンド API のエラーは英語で返る

- バックエンドの API がエラーを返すとき、System は、表示言語によらず、エラーコードと HTTP の状態コードを変えずに、英語の `message`、`error_description`、`detail` を返す。
- **例**：EX-SYSTEM-013-01
