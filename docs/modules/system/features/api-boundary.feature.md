# Feature: API の境界の例

## Rule: REQ-SYSTEM-014 非推奨のインターフェースを呼ぶと Deprecation / Sunset ヘッダーが返る

### Example: EX-SYSTEM-014-01 通常経路

- Given 安定版のインターフェースに `deprecated_since` が設定されている
- When APIConsumer が非推奨とされたインターフェースを呼び出す
- Then レスポンスに `Deprecation` ヘッダーが付与される

### Scenario Outline: 条件ごとの結果

- Given 安定版のインターフェースに `deprecated_since` が設定されている
- When APIConsumer が非推奨とされたインターフェースを呼び出す
- But <condition>
- Then <result>

#### Examples:

  | example_id | condition | result |
  | --- | --- | --- |
  | EX-SYSTEM-014-02 | インターフェースに `sunset_at` も設定されている | レスポンスに `Sunset` ヘッダーも付与される |
  | EX-SYSTEM-014-03 | インターフェースに `deprecated_since` が設定されていない | レスポンスに `Deprecation` ヘッダーは付与されない |

## Rule: REQ-SYSTEM-020 テナント横断の操作はシステム経路とシステムコンソールだけに置く

### Example: EX-SYSTEM-020-01 通常経路

- Given 制御面テナントに所属する `system_admin` の操作者が両方のコンソールへ到達できる
- When 操作者がテナント管理コンソールの監査ログ画面とジョブ画面を開く
- Then どちらの画面にもテナント横断への切替 UI が無く、要求先テナントの記録だけが表示される
- When 操作者がシステムコンソールの監査ログ画面とジョブ画面を開く
- Then どちらの画面も全テナント固定のシステム経路だけを呼び、対象テナントを列として常時表示する
- When 操作者がシステムコンソールでジョブの取り消しを指示する
- Then 確認には対象の `tenant_id`、ジョブ種別、ジョブ ID が示される

### Scenario Outline: 条件ごとの結果

- Given 制御面テナントに所属する `system_admin` の操作者が両方のコンソールへ到達できる
- When <condition>
- But <condition_2>
- Then <result>

#### Examples:

  | example_id | condition | condition_2 | result |
  | --- | --- | --- | --- |
  | EX-SYSTEM-020-02 | 操作者がテナント管理コンソールの監査ログ画面とジョブ画面を開く | テナント管理コンソールの URL に横断を求める状態が残っている | その状態は検証済みの検索条件から落ち、要求先テナントの表示へ戻る |
  | EX-SYSTEM-020-03 | 操作者がシステムコンソールの監査ログ画面とジョブ画面を開く | 操作者が制御面主体の資格を持たない | システムコンソールへは入れずテナント管理コンソールへ送り返され、システム経路も拒否する |

## Rule: REQ-SYSTEM-021 フロントエンドゲートウェイの経路許可リストは組み立て済みの経路表と照合され乖離を検出できる

### Background:

- Given 参照実装のフロントエンドゲートウェイは、API へ中継するパスを設定上の許可リストで選ぶ
- And 組み立て済みの経路それぞれについて、ゲートウェイを通すべきか通してはならないかが、経路の登録と同じ場所で分類されている

### Example: EX-SYSTEM-021-01 通常経路

- When 許可リストと組み立て済みの経路表を突き合わせる
- Then 通すべきと分類された経路は、ホスト形式と `/realms/{tenant_id}` 配下のパス形式の両方で許可リストに一致する
- Then 通してはならないと分類された経路は、どの許可リストにも一致しない
- Then 突き合わせは成功し、Operator は参照設定が実行時の経路表を覆っていることを確かめられる

### Example: EX-SYSTEM-021-02 通すべき経路が許可リストから外れている

- When 許可リストと組み立て済みの経路表を突き合わせる
- But 通すべきと分類された経路がいずれかの許可リストに一致しない
- Then 突き合わせは失敗し、到達できない経路と、それを欠いている許可リストを報告する

### Example: EX-SYSTEM-021-03 通してはならない経路が許可リストに入っている

- When 許可リストと組み立て済みの経路表を突き合わせる
- But `MetricsExposition` のように通してはならないと分類された経路がいずれかの許可リストに一致する
- Then 突き合わせは失敗し、公開してはならない経路と、それを通している許可リストを報告する

### Example: EX-SYSTEM-021-04 許可リストを読み取れない

- When 許可リストと組み立て済みの経路表を突き合わせる
- But 設定の書式が変わり、いずれかの許可リストを読み取れない
- Then 突き合わせは失敗し、照合が空振りしたことを報告する
