# ApiTokens の設計

この文書は、ApiTokens の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [ApiTokens](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の機能仕様の「実現方式」の節に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 委譲 | [モデル](../README.md#モデル) | 保存する項目は仕様のモデルが、テーブルの定義はスキーマファイルが扱う |
| セキュリティ設計 | 委譲 | [API アクセストークンの認証と認可](../authentication/README.md#概要) | 認証と認可の規則はAPI アクセストークンの認証と認可が、スコープの割り当ては TypeSpec が扱う |
| 検証設計 | 固有設計 | [担当文書](verification.md#パースの境界のファズテスト) | パースの境界のファズテスト、共有の拒否の宣言 |
