# ApiTokens の設計

この文書は、ApiTokens の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [ApiTokens](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。

| 設計領域 | 内容 |
| --- | --- |
| [アーキテクチャ設計](architecture.md) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 該当なし：管理 API はシステムの[アプリケーション設計](../../../design/application/README.md)に従い、このモジュールに固有の方式はない |
| データ設計 | 該当なし：保存する項目は仕様の[モデル](../README.md#モデル)が、テーブルの定義はスキーマファイルが扱う |
| インフラストラクチャ設計 | 該当なし：実行基盤に固有の要件はない |
| セキュリティ設計 | 該当なし：認証と認可の規則は[API アクセストークンの認証と認可](../authentication/README.md)が、スコープの割り当ては TypeSpec が扱う |
| 信頼性設計 | 該当なし：モジュールに固有の障害の経路はない |
| 性能設計 | 該当なし：システムの[性能設計](../../../design/performance/README.md)に従い、このモジュールに割り当てた品質要件はない |
| オブザーバビリティ設計 | 該当なし：システムの[オブザーバビリティ設計](../../../design/observability/README.md)に従い、このモジュールに固有の信号はない |
| [検証設計](verification.md) | パースの境界のファズテスト、共有の拒否の宣言 |
