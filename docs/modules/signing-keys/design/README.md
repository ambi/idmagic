# SigningKeys の設計

この文書は、SigningKeys の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [SigningKeys](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の機能仕様の「実現方式」の節に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 固有設計 | [担当文書](data.md#状態の表し方) | 状態の表し方、排他 |
| インフラストラクチャ設計 | 委譲 | [秘密情報の設計](../../../design/security/secrets.md#対象範囲) | Vault の配置はシステムの秘密情報の設計が扱う |
| セキュリティ設計 | 委譲 | [モデル](../README.md#モデル)、[秘密情報の設計](../../../design/security/secrets.md#対象範囲) | 鍵素材の置き場所は仕様のモデルが、鍵の種類ごとの扱いはシステムの秘密情報の設計が扱う |
| 信頼性設計 | 委譲 | [鍵の提供元と健全性](../provider/README.md#モデル) | 提供元の障害の扱いは鍵の提供元と健全性のモデルの節が扱う |
