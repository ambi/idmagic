# SigningKeys のリスク

この文書は、SigningKeys の既知の欠陥、技術的負債、受容したリスクを扱う。
脅威は[脅威モデル](../../design/security/threat-model.md)に置く。

| リスク | 現状 | 影響 |
| --- | --- | --- |
| 準備した XML 鍵は管理者が切り替えるまで署名に使われない | `idmagic-batch signing-key-lifecycle` は、周期を過ぎた `XmlFederationSigning` の鍵の集合に次の鍵を準備するが、有効にしない。準備を管理者へ知らせる通知はない | 管理者が鍵の一覧で `Prepared` の鍵に気づき、連携先へ登録して切り替えるまで、同じ署名鍵が使われ続ける |
| 検証用の鍵の無効化がドメインイベントを発行しない | 無効化はイベントを発行しない | 鍵の無効化が監査の記録に残らない |
