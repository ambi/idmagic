`admin-roles`　`/admin/roles`

定義済みのロールと権限、付与人数を確認する

| 項目 | 内容 |
| --- | --- |
| 主担当 | [OAuth2](../README.md) |
| 利用者 | テナント管理者 |
| 入口 | 管理メニュー |
| 利用条件 | 対象テナントの管理権限で参照し、操作の認可は API が判断する。 |
| 表示内容 | ロールの一覧と選択した詳細、許可する操作と付与されたユーザー、再取得と詳細への入口 |

利用手順は[OAuth2 のページ一覧](README.md)にまとめる。

個々の入力項目は実装の画面が持ち、受理範囲は API 契約と[共通の UI 設計](../../../design/application/user-interface.md)の検証の分担が定める。

## 操作と結果の詳細

| 操作 | 起点 | 契機 | 条件 | API | 結果 | 到達先 | データ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| refresh | ready | 再取得または選択 | 常時 | IdMagic.OAuth2.Operations.ListAdminRolePolicies | ロールと付与されたユーザーを表示する | [ロール一覧](admin-roles.md) / ready | 対象の識別子と操作の入力値 |
| detail | ready | 詳細 | 常時 | UI 内の操作 | 移動先を表示する | [ロール詳細](admin-role-detail.md) / ready | なし |
| users | ready | 付与ユーザーを開く | 常時 | UI 内の操作 | 移動先を表示する | [ユーザー一覧](../../identity-management/pages/admin-users.md) / ready | なし |

## 表示状態

| 状態 | 表示 |
| --- | --- |
| ready | 取得した内容を表示する。 |
| loading | ページ移動中は直前の表示を保つ。初回の取得はルーターが扱う。 |
| error | 表示できなければ共通エラーを表示し、操作失敗は操作の近くに残す。 |
| forbidden | 権限不足を表示し、未反映の状態を保つ。 |
| expired | 認証が必要なページでは再認可し、復帰できなければログインへ移る。 |
| success | 成功した操作を一度通知し、表示内容を再取得する。 |
