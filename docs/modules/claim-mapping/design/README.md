# ClaimMapping の設計

この文書は、ClaimMapping の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [ClaimMapping](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の機能仕様の「実現方式」の節に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 対象外 | — | このモジュールは HTTP の操作と UI を持たない |
| データ設計 | 対象外 | — | このモジュールは永続状態を保存しない。ポリシーは信頼先の Aggregate の一部として、そのモジュールが保存する |
| セキュリティ設計 | 委譲 | [クレームの発行](../issuance/README.md#セキュリティ上の考慮) | 公開できない属性を拒否する下限は、クレームの発行のセキュリティ上の考慮の節が扱う |
