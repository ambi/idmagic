# WsFederation の検証

この文書は、WsFederation の要件と統制のうち、例のテストのほかに確かめているものを扱う。
システム全体の検証の方式は[検証設計](../../../design/verification/README.md)に従う。

## パースの境界のファズテスト

パッシブサインインの `wreply` の解決と、WS-Trust の RST のエンベロープの解析は、Go のネイティブのファジングの対象である。

| 対象 | オラクル |
| --- | --- |
| `ValidateSignIn` | 返す返信先は、必ず RP に登録した集合の要素である。`wreply` を指定した要求が通ったなら、その値とバイト単位で一致する |
| `ParseRST` | 拒否したエンベロープから Username や `AppliesTo` を持ち出さない |

`wreply` の一致が、接頭辞の一致や正規化を伴う一致へ退行すると、攻撃者は RP のドメインの配下に見える別の宛先へトークンを配送できる。
XML の実体参照を展開しないことは、SAML と同じく回帰テストで押さえる。
