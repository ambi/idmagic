# WsFederation の設計

この文書は、WsFederation の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [WsFederation](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。

| 設計領域 | 内容 |
| --- | --- |
| [アーキテクチャ設計](architecture.md) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 該当なし：管理 API はシステムの[アプリケーション設計](../../../design/application/README.md)に従い、プロトコルの形は[標準仕様](../standards.md)が定める |
| データ設計 | 該当なし：RP の項目は仕様の[モデル](../README.md#モデル)が、テーブルの定義はスキーマファイルが扱う |
| インフラストラクチャ設計 | 該当なし：実行基盤に固有の要件はない |
| [セキュリティ設計](security.md) | テナント単位の署名、認可の境界 |
| 信頼性設計 | 該当なし：Entra のフェデレーションの障害の切り分けは[RP と Entra フェデレーションの管理の設計](../relying-party/design.md)が扱い、それ以外に固有の仕組みはない |
| 性能設計 | 該当なし：システムの[性能設計](../../../design/performance/README.md)に従い、このモジュールに割り当てた品質要件はない |
| オブザーバビリティ設計 | 該当なし：発行と拒否はドメインイベントで監査に残り、それ以外はシステムの[オブザーバビリティ設計](../../../design/observability/README.md)に従う |
| [検証設計](verification.md) | パースの境界のファズテスト |
