# WsFederation の設計

この文書は、WsFederation の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [WsFederation](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 委譲 | [標準仕様](../standards.md#web-services-federation-language-ws-federation-version-12) | 管理 API はシステムのアプリケーション設計に従い、プロトコルの形は標準仕様が定める |
| データ設計 | 委譲 | [モデル](../README.md#モデル) | RP の項目は仕様のモデルが、テーブルの定義はスキーマファイルが扱う |
| セキュリティ設計 | 固有設計 | [担当文書](security.md#テナント単位の署名) | テナント単位の署名、認可の境界 |
| 信頼性設計 | 委譲 | [RP と Entra フェデレーションの管理の設計](../relying-party/design.md#信頼性) | Entra のフェデレーションの障害の切り分けはRP と Entra フェデレーションの管理の設計が扱い、それ以外に固有の仕組みはない |
| 検証設計 | 固有設計 | [担当文書](verification.md#パースの境界のファズテスト) | パースの境界のファズテスト |
