# SharedSignals の設計

この文書は、SharedSignals の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [SharedSignals](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 委譲 | [標準仕様](../standards.md#security-event-token-set) | 管理 API はシステムのアプリケーション設計に従い、受信のエンドポイントの形は標準仕様が定める |
| データ設計 | 委譲 | [モデル](../README.md#モデル) | Aggregate とその関係は仕様のモデルが、テーブルの定義はスキーマファイルが扱う |
| セキュリティ設計 | 委譲 | [SET の受信](../receiver/README.md#セキュリティ上の考慮)、[失効エポック](../revocation/README.md#セキュリティ上の考慮) | 受信の検証はSET の受信が、エポックの公開の範囲は失効エポックのセキュリティ上の考慮の節が扱う |
| 信頼性設計 | 委譲 | [SET の配送の設計](../transmitter/design.md#信頼性) | 配送の再試行と配信不能はSET の配送の設計が扱う |
