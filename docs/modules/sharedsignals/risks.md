# SharedSignals のリスク

この文書は、SharedSignals の既知の欠陥、技術的負債、受容したリスクを扱う。
脅威は[脅威モデル](../../design/security/threat-model.md)に置く。

| リスク | 現状 | 影響 |
| --- | --- | --- |
| やり直しは保存した SET の署名を作り直さない | 署名鍵はローテーションの 7 日後に JWKS から外れるが、配送は作成時の署名のまま送る | 鍵が外れた後のやり直しは受信側で検証できず、再び `dead_letter` になる。理由は `last_error` に残る |
