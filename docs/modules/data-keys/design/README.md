# DataKeys の設計

この文書は、DataKeys の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [DataKeys](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の機能仕様の「実現方式」の節に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 委譲 | [DEK のライフサイクル](../lifecycle/README.md#モデル) | 鍵のバージョンの保存と破棄の扱いはDEK のライフサイクルのモデルの節が、テーブルの定義はスキーマファイルが扱う |
| インフラストラクチャ設計 | 委譲 | [秘密情報の設計](../../../design/security/secrets.md#対象範囲) | マスターキーのプロバイダーの配置はシステムの秘密情報の設計が扱う |
| セキュリティ設計 | 固有設計 | [担当文書](security.md#追加認証データによる束縛) | 追加認証データによる束縛、復号の失敗時の拒否 |
| 信頼性設計 | 委譲 | [DEK のライフサイクルの設計](../lifecycle/README.md#信頼性) | 再暗号化の再開と取りこぼしの回収はDEK のライフサイクルの設計が扱う |
