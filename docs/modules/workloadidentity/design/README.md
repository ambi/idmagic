# WorkloadIdentity の設計

この文書は、WorkloadIdentity の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [WorkloadIdentity](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 委譲 | [モデル](../README.md#モデル) | 二つの Aggregate の関係と削除の扱いは仕様のモデルが、テーブルの定義はスキーマファイルが扱う |
| セキュリティ設計 | 委譲 | [アテステーションの交換](../attestation-exchange/README.md#セキュリティ上の考慮) | 交換の経路が管理者の権限を通らないことと、テナントの境界はアテステーションの交換のセキュリティ上の考慮の節が扱う |
| 信頼性設計 | 委譲 | [アテステーションの交換の設計](../attestation-exchange/design.md#信頼性) | JWKS の取得の失敗の扱いはアテステーションの交換の設計が扱う |
