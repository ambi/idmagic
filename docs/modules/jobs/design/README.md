# Jobs の設計

この文書は、Jobs の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Jobs](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 委譲 | [永続キューの設計](../queue/design.md#アーキテクチャ) | 取得とリースと重複の排除の仕組みは永続キューの設計が、テーブルの定義はスキーマファイルが扱う |
| インフラストラクチャ設計 | 委譲 | [永続キューの設計](../queue/design.md#アーキテクチャ) | レーンごとの Deployment は永続キューの設計が、それ以外はシステムのインフラストラクチャ設計が扱う |
| 信頼性設計 | 委譲 | [永続キューの設計](../queue/design.md#信頼性) | 再試行、停止、回復は永続キューの設計が扱う |
| 性能設計 | 委譲 | [永続キュー](../queue/README.md#概要) | レーンによるキャパシティの隔離は永続キューが扱い、それ以外はシステムの性能設計に従う |
