# Jobs の設計

この文書は、Jobs の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Jobs](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。

| 設計領域 | 内容 |
| --- | --- |
| [アーキテクチャ設計](architecture.md) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| アプリケーション設計 | 該当なし：管理 API はシステムの[アプリケーション設計](../../../design/application/README.md)に従い、このモジュールに固有の方式はない |
| データ設計 | 該当なし：取得とリースと重複の排除の仕組みは[永続キューの設計](../queue/design.md)が、テーブルの定義はスキーマファイルが扱う |
| インフラストラクチャ設計 | 該当なし：レーンごとの Deployment は[永続キューの設計](../queue/design.md)が、それ以外はシステムの[インフラストラクチャ設計](../../../design/infrastructure/README.md)が扱う |
| セキュリティ設計 | 該当なし：テナントの境界は各機能仕様のセキュリティ上の考慮の節が扱う |
| 信頼性設計 | 該当なし：再試行、停止、回復は[永続キューの設計](../queue/design.md)が扱う |
| 性能設計 | 該当なし：レーンによるキャパシティの隔離は[永続キュー](../queue/README.md)が扱い、それ以外はシステムの[性能設計](../../../design/performance/README.md)に従う |
| オブザーバビリティ設計 | 該当なし：ジョブの状態の変化はドメインイベントで監査に残り、それ以外はシステムの[オブザーバビリティ設計](../../../design/observability/README.md)に従う |
| 検証設計 | 該当なし：システムの[検証設計](../../../design/verification/README.md)に従う |
