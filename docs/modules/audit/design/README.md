# Audit の設計

この文書は、Audit の設計を設計領域ごとに索引する。
このモジュールが外へ約束することは、仕様の [Audit](../README.md) と各機能仕様が定める。
一つの機能だけの仕組みは、その機能の `design.md` に置く。
記載のない領域には[共通設計](../../../design/README.md#共通設計の適用範囲)を適用する。

| 設計領域 | 区分 | 参照先 | 内容 |
| --- | --- | --- | --- |
| アーキテクチャ設計 | 固有設計 | [担当文書](architecture.md#文脈と範囲) | 文脈と範囲、解決戦略、構成要素、実行時の流れ |
| データ設計 | 委譲 | [監査イベントの検索の設計](../event-search/design.md#データ)、[データのライフサイクル](../../../design/data/lifecycle.md#データの区分と消え方) | 検索属性の副表は監査イベントの検索の設計が、保持期間と削除はデータのライフサイクルが扱う |
| セキュリティ設計 | 委譲 | [監査イベントの検索](../event-search/README.md#セキュリティ上の考慮) | 経路による範囲の固定とカーソルの扱いは監査イベントの検索のセキュリティ上の考慮の節が扱う |
| 信頼性設計 | 委譲 | [Audit のリスク](risks.md#audit-のリスク) | 記録の追記の失敗の扱いは配信点の側にあり、Audit のリスクに載せる |
| 検証設計 | 固有設計 | [担当文書](verification.md#パースの境界のファズテスト) | パースの境界のファズテスト |
