# Audit のリスク

この文書は、Audit の既知の欠陥、技術的負債、受容したリスクを扱う。
脅威は[脅威モデル](../../design/security/threat-model.md)に置く。

| リスク | 現状 | 影響 |
| --- | --- | --- |
| 保持期間が、監査の記録の保持の目標より短い | 監査の記録を GDPR 第 30 条を根拠に 7 年間保持する目標がある一方、保持期間の掃引は固定のデフォルトの方針で動き、成功と一般の監査を 365 日、失敗の詳細を 30 日で消す。方針を設定で変える手段はない | 掃引を実行する配置では、7 年を待たずに監査の記録が消える |
| 通常経路の監査の欠落を許容する | 配信点が検知した変換と追記の失敗を API と Worker の指標とログへ記録し、[対応手順](../../runbooks/audit-record-write-failure.md) へつなぐ。発行前の停止を検知する仕組みと自動補充は持たない | 業務の結果が残り、監査だけが欠ける場合がある。指標とログの収集前の停止では観測も失われ得る。原因を直しても過去の記録は自動回復しない |
