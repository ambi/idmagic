# Audit のセキュリティ

この文書は、Audit の信頼境界で、外部から届く入力の解析をどう確かめるかを扱う。
制御の種類ごとの検証手段は[脅威モデル](../../design/security/threat-model.md#制御の種類ごとの検証手段)が定める。

## パースの境界のファズテスト

監査の検索フィルターの解析は、Go のネイティブのファジングの対象である。
オラクルは、受理した式の属性が検索属性の登録簿に存在し、演算子がその属性の許す集合に含まれることである。
フィルターはこの先でクエリの組み立てに使われるため、許可の集合を経ない属性や演算子が通ると、監査ログの検索が意図しないカラムや比較へ広がる。
