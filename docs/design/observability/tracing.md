# トレース設計

`OBSERVABILITY=otel` のとき、API は受信リクエストへ `trace_id` と `span_id` を割り当て、ログと関連付け、OTLP コレクターへ送る。
`X-Request-ID` は別の相関軸として常にレスポンスとログに残す。

クライアントが送る相関値は既定で信用せず、信頼できる境界プロキシが生成または無害化する場合だけ受信値を使う。
受信する値には長さと文字種の制限を課す。

データベース、外部 HTTP、非同期ジョブへ文脈を伝播し、標本化と保持を環境ごとに定義する設計は未完成である。
実装と検証は [wi-107](../../../work-items/wi-107-opentelemetry-distributed-tracing.md) が扱う。
未実装のスパンを、`request_id` が存在することを理由に取得済みとは扱わない。
