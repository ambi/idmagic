# 基盤設計

## 環境

ローカル環境は Docker Compose またはメモリ実装、クラスター環境は Kubernetes の base と dev または prod overlay、GCP は独立した参照例を持つ。
これらは選択可能な参照構成であり、リポジトリは本番への適用状態を記録しない。

## 計算資源とストレージ

API、UI ゲートウェイ、レーン別ワーカーを独立した実行枠へ置く。
バッチは CronJob または外部スケジューラーから一回限りで起動する。
PostgreSQL は構成資材の外にある管理対象サービスまたは別の運用単位として提供し、業務データと共有すべき短命状態を保持する。

## 設定の所有

`infra/k8s/base/` は環境共通の資材、`overlays/` は環境差、`infra/docker/` はローカル構成を持つ。
アプリケーション設定の項目、既定値、検証規則はコードから生成する `CONFIGURATION.md` が示す。
秘密値とイメージダイジェストは配備時に注入し、Git の資材へ保存しない。

## 未確定事項

クラウド事業者ごとの可用性、費用、データ所在地、保守窓は採用環境が決まらないと確定できない。
`infra/deploy/gcp/` の構成と費用は GCP の例であり、全配備の保証値ではない。
