# インフラストラクチャ設計

IdMagic を動かすコンピューティング、ストレージ、ネットワークと、リポジトリが提供する構成ファイルの責任分界を扱う。
構成要素と配置の対応は[デプロイメントアーキテクチャ](../architecture/deployment.md)で定める。

| 文書 | 内容 |
| --- | --- |
| [プラットフォーム設計](platform.md) | デプロイプロファイル別のコンピューティング、ストレージ、シークレットの注入、スキーマ適用、スケール単位、構成管理 |
| [ネットワーク設計](network.md) | デプロイプロファイル別のエッジの TLS 終端と L7 の防御、セグメンテーション、ファイアウォールルール、Egress、DNS と証明書、リスナーの公開範囲、管理アクセス |

デプロイプロファイルの一覧と、構成要素の配置先は[デプロイメントアーキテクチャ](../architecture/deployment.md)で定める。
