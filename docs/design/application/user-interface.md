# ユーザーインターフェース設計

管理、アカウント、認証の各画面は、機能ごとに `frontend/src/features/<feature>/` へ置き、ビュー、局所コンポーネント、表示ロジック、試験、`ja` と `en` の辞書を同じ境界に置く。
機能に属さない再利用部品だけを `frontend/src/components/` に置く。

画面の情報構造は、利用者が対象テナント、対象資源、現在の状態、実行できる操作、操作結果を識別できる順序にする。
破壊的または取り消せない操作は対象と結果を確認できる文言を持たせ、権限がない操作を成功したように見せない。

ユーザー向け文字列は `*.i18n.ts` の辞書を正本とし、日本語と英語を同じ変更で更新する。
アクセシビリティの規範は[全体の標準仕様](../../standards.md)が持ち、画面ごとの実装はセマンティック HTML、キーボード操作、可視フォーカス、ラベルとエラーの関連、状態通知でその規範を満たす。

URL、画面ごとの表示項目、色や余白の値は実装から導けるため、この文書へ一覧を複製しない。
