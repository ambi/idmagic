# アプリケーション設計

この文書は、アプリケーション設計の文書の入口である。
アプリケーション設計は、複数の機能へ共通する API の契約、モジュールの設計の判断基準、バックエンドとフロントエンドの構成、UI を扱う。
アプリケーションの詳細な機能仕様は[各モジュール](../../modules/README.md)と TypeSpec で定める。

| 文書 | 内容 |
| --- | --- |
| [API ガイドライン](api-guidelines.md) | 外部契約を横断する HTTP と API の規則 |
| [設計ガイドライン](design-guidelines.md) | モジュール、型、依存、作用、エラーの設計ガイドライン |
| [バックエンド設計](backend.md) | モジュール内部の層、パッケージの種類、依存規則と公開範囲、モジュール間イベント、HTTP ルーティング、起動時の組み立て |
| [フロントエンド設計](frontend.md) | 機能スライスの境界、ルーティング、データ取得と状態、ビルドと配信、テストの置き場所 |
| [ユーザーインターフェース設計](user-interface.md) | 画面を跨ぐ情報構造、操作、表示状態、フォーム、一覧、通知、国際化、アクセシビリティ |
