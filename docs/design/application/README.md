# アプリケーション設計

アプリケーションの詳細な機能仕様は[各 Bounded Context](../../domain/)とTypeSpecが持つ。
このディレクトリは、複数の機能へ共通する契約、モジュール、UI の設計ガイドラインを持つ。

| 文書 | 責務 |
| --- | --- |
| [API ガイドライン](api-guidelines.md) | 外部契約を横断する HTTP と API の規則 |
| [設計ガイドライン](design-guidelines.md) | モジュール、型、依存、作用、エラーの設計ガイドライン |
| [フロントエンド設計](frontend.md) | 機能スライスの境界、ルーティング、データ取得と状態、ビルドと配信、テストの置き場所 |
| [ユーザーインターフェース設計](user-interface.md) | 画面を跨ぐ情報構造、操作、表示状態、フォーム、一覧、通知、国際化、アクセシビリティ |
