# 性能設計

品質目標を満たすための負荷分布、資源見積もり、拡張単位、律速点、過負荷保護を扱う。

| 文書 | 内容 |
| --- | --- |
| [キャパシティ設計](capacity.md) | 想定ワークロード、ピーク時のリクエスト率、サイジング計算式、仮定値の根拠、再計算の条件、ロードシェディング順序 |
| [スケーリング・負荷設計](scaling.md) | スケーリング単位、オートスケール、アドミッションコントロール、バックプレッシャー、遮断、再試行の所有 |

目標値と測定境界は[品質要求](../../requirements/quality.md)で定める。
現在の数値は実測ではなく、ステージングでの検証もまだ行っていない。
