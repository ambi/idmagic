# 信頼性設計

品質要求で定めた可用性と復旧目標を、障害モデル、冗長化、切り替え、ロードシェディング、バックアップと復元へ具体化する。

| 文書 | 責務 |
| --- | --- |
| [可用性設計](availability.md) | 障害単位ごとの検知と対処、PostgreSQL の可用性、健全性の確認と停止、共有状態、ロードシェディング |
| [リカバリ設計](recovery.md) | データ保護の三つの手段、早期検知の仕組み、データの種類ごとの取得方式と復元試験、暗号鍵の喪失、復元の順序、災害の範囲 |

可用性の目標値は[品質要求](../../requirements/quality.md)、負荷不足への対処は[スケーリング・負荷設計](../performance/scaling.md)、実作業の手順は[運用手順](../../runbooks/)に書く。
