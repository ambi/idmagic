# WI-570: account スコープのアクセストークンがレルムの IdMagic API を audience に持つ

作業項目は `wi-570-account-scoped-tokens-name-no-audience` である。

`resource` を指定せずに発行したアクセストークンのうち、`account:` で始まるスコープを持つものは、`aud` にレルムの発行者識別子（レルムの IdMagic API）を持つ。
以前は、`resource` を指定しないすべてのアクセストークンが `aud` に `client_id` を持っていた。
account スコープを持たないトークンと、`resource` を指定したトークンの `aud` は変わらない。

account リソースサーバーは、account スコープを持つトークンの `aud` が要求先レルムの発行者識別子を含むことを確かめ、含まないトークンを 401 の `invalid_token` で拒否する。
別の資源へ宛てたトークンは、同じスコープ名を持っていても account API を操作できない。
ポータル境界のスコープ（`idmagic.account`、`idmagic.admin`）だけを持つトークンは、この検査を受けない。

この変更は RFC 9068 §3 に従う。
`resource` を含まない要求では、`scope` からデフォルトの資源を推定して `aud` に入れる。
管理発行の API アクセストークンは既に同じ値を `aud` に持つため、影響を受けない。

観測できる振る舞いは、`docs/domain/oauth2/scenarios.feature.md` の `REQ-OAUTH2-001` と、`docs/domain/oauth2/standards.md` の `RFC9068-DEFAULT-AUDIENCE` が定める。
