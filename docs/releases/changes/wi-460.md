# WI-460: Restrict cross-tenant operations to control-plane actors

作業項目は `wi-460-cross-tenant-health-control-plane-membership` である。

WI-460 は、テナント横断の署名鍵ヘルスと DEK ヘルスを、制御面テナントに所属し、有効ロールに `system_admin` を持ち、制御面テナントの経路を使う User だけに限定する。

制御面テナント外に所属する `system_admin` には HTTP 403 を返し、他テナントの識別子や鍵運用状態を応答へ含めず、横断の健全性収集も実行しない。

この条件は Tenancy、Audit、Jobs、SigningKeys、DataKeys の制御面操作で共有する。

Jobs では、正規の制御面主体が `admin` ロールを併有しなくても、テナント横断の一覧、詳細参照、取消しを行えるようになった。

規範上の拒否条件は [REQ-SIGNINGKEYS-009](../../contexts/signing-keys/scenarios.md#req-signingkeys-009-制御面主体ではない管理者はシステムコンソールの署名鍵ヘルスにアクセスできない) と [REQ-DATAKEYS-006](../../contexts/data-keys/scenarios.md#req-datakeys-006-制御面主体はテナント横断で-dek-の健全性を一覧できる) が定める。
