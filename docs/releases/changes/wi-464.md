# 監査イベントの非同期エクスポート

テナント管理画面とシステム管理画面のエクスポートは、バックグラウンドで全件を生成する。
要求者は状態を確認し、未完了の要求を取り消し、完成した JSON を期限内にダウンロードできる。
生成中も API は監査イベント全体をメモリへ保持しない。

最大イベント数、最大バイト数と有効期限は、[監査エクスポート](../../modules/audit/features/event-export.md)の設定で変更できる。
上限を超えた場合は失敗となり、部分成果物は公開されない。
横断成果物の保存バイト数は制御面テナントへ計上する。

同期 API は 2026-10-25 から非推奨となる。
Sunset は 2027-10-25 とし、実際の削除には初回公開からも最低 12 か月を置く。
既存の自動化は[移行手順](../upgrades/wi-464.md)に従う。
