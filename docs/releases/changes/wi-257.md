# WI-257: OIDC ログアウトを接続済みアプリへ伝播する

作業項目は `wi-257-oidc-front-back-channel-logout-notifications` である。

利用者が `/end_session` でログアウトすると、同じ OIDC セッションへ参加したアプリにもログアウトを通知する。

Front-Channel Logout を設定したアプリは、ログアウト応答に埋め込まれる iframe を通して通知を受ける。

Back-Channel Logout を設定したアプリは、署名済み logout token を HTTPS POST で受ける。

一時的な配送失敗は永続ジョブで再試行し、通知状態から成功または最終失敗を追跡できる。

外部配送先は HTTPS に限定し、private IP、userinfo、fragment、危険な redirect を拒否する。

既存のローカルセッションと refresh token family の失効を先に確定するため、接続先アプリの障害が idmagic 自身のログアウトを妨げることはない。

規範上の振る舞いは [`REQ-OAUTH2-025`](../../contexts/oauth2/scenarios.feature.md#rule-req-oauth2-025-セッション失効時は-backchannel_logout_uri-を登録済みの-rp-へログアウトトークンを配信する) と [`OIDC-FRONTCHANNEL-IFRAME`](../../contexts/oauth2/standards.md#openid-connect-front-channel-logout-10) が定める。
