# WI-460: Migrate cross-tenant operators to the control-plane tenant

作業項目は `wi-460-cross-tenant-health-control-plane-membership` である。

WI-460 の配備前に、制御面テナント外の User または Group に付与された `system_admin` を確認する。

このような User は、配備後に署名鍵ヘルス、DEK ヘルス、テナント横断の監査とジョブ操作へ到達できない。

引き続きテナント横断の運用を担当する利用者には、制御面テナントの有効な User を用意し、その User または所属 Group の有効ロールへ `system_admin` を付与する。

Jobs の横断運用には `admin` の追加付与は不要である。

この変更は保存済み User、Group、ロール割当てを変更せず、データ移行も行わない。

後退すると以前の認可条件へ戻り、制御面テナント外の `system_admin` が再び他テナントの鍵運用状態を取得できるため、障害切り分け以外の目的では後退しない。

互換性境界と拒否後の非観測条件は [REQ-SIGNINGKEYS-009](../../contexts/signing-keys/scenarios.md#req-signingkeys-009-制御面主体ではない管理者はシステムコンソールの署名鍵ヘルスにアクセスできない) と [REQ-DATAKEYS-006](../../contexts/data-keys/scenarios.md#req-datakeys-006-制御面主体はテナント横断で-dek-の健全性を一覧できる) が定める。
