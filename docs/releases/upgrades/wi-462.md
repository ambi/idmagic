# WI-462: テナント横断の呼出しをシステム API へ移す

作業項目は `wi-462-control-plane-console-single-entry` である。

WI-462 の配備前に、テナント管理 API へ `all_tenants=true` を付けている呼出しと、`system_admin` の資格で他テナントのジョブや監査イベントを操作している呼出しを洗い出す。どちらも配備後は要求先テナントに閉じるため、横断を前提にした自動化は結果が静かに変わる。

## 監査イベント

`GET /api/admin/v1/audit_events` とその詳細およびエクスポートは、`all_tenants` を受け付けなくなった。付けても無視され、要求元の所属テナントだけが返る。

横断が必要な呼出しは次へ移す。

| 変更前 | 変更後 |
| --- | --- |
| `GET /api/admin/v1/audit_events?all_tenants=true` | `GET /api/admin/v1/system/audit_events` |
| `GET /api/admin/v1/audit_events/export?all_tenants=true` | `GET /api/admin/v1/system/audit_events/export` |
| `GET /api/admin/v1/audit_events/{id}` (他テナントの id) | `GET /api/admin/v1/system/audit_events/{id}` |

絞り込みの文法、ページングのカーソル、応答の形はどちらの経路でも同じである。検索フォームの選択肢を返す `GET /api/admin/v1/audit_events/search_options` は 1 本のままで、システム側からも同じものを呼ぶ。

## ジョブ

`GET /api/admin/v1/jobs` は `all_tenants` を受け付けなくなった。詳細と取消しも要求先テナントに閉じ、他テナントの id は存在しないものとして扱われる。

| 変更前 | 変更後 |
| --- | --- |
| `GET /api/admin/v1/jobs?all_tenants=true` | `GET /api/admin/v1/system/jobs` |
| `GET /api/admin/v1/jobs/{job_id}` (他テナントの id) | `GET /api/admin/v1/system/jobs/{job_id}` |
| `POST /api/admin/v1/jobs/{job_id}/cancel` (他テナントの id) | `POST /api/admin/v1/system/jobs/{job_id}/cancel` |

## 呼出しの資格

システム API は、制御面テナントに所属し、有効ロールに `system_admin` を持ち、制御面テナントの経路で呼ぶことの 3 つをすべて満たす利用者だけが通る。`admin` ロールの併せ持ちは要らない。3 つのいずれかを欠くと `AccessDeniedError` になる。API アクセストークンで呼ぶ場合に要するスコープは、変更前と同じ `audit:read`、`jobs:read`、`jobs:cancel` である。

テナント管理 API の側は、要求先テナントの `admin` ロールを要するようになった。`system_admin` だけを持ち `admin` を持たない利用者は、これまで `/api/admin/v1/jobs` を呼べていたが、配備後は拒否される。この利用者の横断運用はシステム API が引き継ぎ、制御面テナント自身のジョブもそちらから見える。テナント管理 API を引き続き使う必要がある場合は、その利用者または所属 Group の有効ロールへ `admin` を加える。

## カーソル

ページングのカーソルは範囲に束縛される。テナント管理経路で発行したカーソルをシステム経路へ、またはその逆へ渡すと `InvalidRequestError` になる。経路をまたいで続きを取る運用があれば、移行先の経路で先頭ページから取り直す。

## 画面

テナント管理コンソールの監査画面とジョブ画面から横断の切替が消えた。横断は `/system/audit-events` と `/system/jobs` にある。横断を求める URL 状態を含む古いブックマークは、テナント内表示として開く。

データ移行と設定変更は要らない。

互換性境界は [REQ-AUDIT-007](../../contexts/audit/scenarios.feature.md)、[REQ-JOBS-015](../../contexts/jobs/scenarios.feature.md)、[REQ-SYSTEM-020](../../contexts/system/scenarios.feature.md) が定める。
