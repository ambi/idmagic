# 日本語文章規則

リポジトリ内の人が読む文章は日本語で記述する。Markdown はタイトル、見出し、表見出し、リンクラベルを含めて日本語とし、同じ内容の英語版を併記しない。ソースコード、TypeSpec、設定、テストに含まれるコメントと説明文も日本語にする。

英語で記述する文章は、API エラーメッセージ、ログメッセージ、CLI ヘルプ、コミットメッセージ、`en` ロケールの利用者向け UI 文言だけとする。`ja` ロケールの利用者向け UI 文言は日本語にする。

識別子、リテラル値、ファイルパス、コマンド、製品名、プロトコル名、規格名、頭字語、外部契約で定められた名前は文章の言語とは区別し、意味を保つため必要な原表記を使う。Go と TypeScript の識別子、データベース列、イベント名、エラーコード、スコープ、`REQ-<CONTEXT>-NNN`、TypeSpec のシンボル、frontmatter のキーはこの扱いに含む。

日本語の文章を執筆または推敲するときは、文章品質と整形の規範として `japanese-tech-writing` スキルを使う。
