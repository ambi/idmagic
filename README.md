# IdMagic

IdMagic は、人間とエージェントのアイデンティティ、認証、委譲、プロビジョニングをテナント単位で管理するアイデンティティ基盤である。

```bash
mise run dev
```

詳しい起動方法は [ローカル開発](docs/development/local-development.md) を参照する。
